# 📢 更新日志

> 感谢您使用漫匣！以下是最新版本的更新内容。

## 🚀 v0.1.2 `(104902302)`

### 📖 EPUB WebView 阅读体验 (EPUB WebView Reader)

- **重建 EPUB spine 与 OPF 识别链路**
  > EPUB 会优先从真实 OPF 目录结构恢复章节、资源路径和版式信息。
  - 支持通过 `META-INF/container.xml`、常见 OPF 文件名和嵌套目录自动定位 package document。
  - 已导入书籍会在打开 WebView 阅读器时对比 OPF，必要时刷新章节资源、媒体类型和版式标记。
  - 解压缓存缺少 spine 资源时会自动重新解压补齐，并跳过仍然缺失的资源，避免空白章节中断阅读。

- **增强封面页与出版物固定版式适配**
  > 封面、插画页和出版物预设版式会按整页内容处理，不再被普通正文分页拉伸或裁切。
  - 新增 `COVER_PAGE`、`IMAGE_PAGE`、`PUBLISHER_LAYOUT` 等版式识别，覆盖 OPF guide、meta cover、cover-image、spine 属性、文件名和 HTML 版式信号。
  - 封面页使用独立 CSS 和 WebView 脚本按视口居中 `contain` 显示，减少封面被裁边、缩放异常或被原页面样式干扰的问题。
  - 出版物固定版式会限制媒体尺寸并按页面比例缩放，适配多看类、插画页和整页图文混排内容。

- **优化 EPUB 分页、背景与跨章节过渡**
  > 阅读器切换 spine 时会更稳，首屏和翻页过程不再容易闪白或变暗。
  - 封面页、图片页和出版物版式统一按单页分页处理，桥接脚本会清理虚拟偏移并保持页码稳定。
  - 跨章节切换前会捕获上一帧快照作为过渡遮罩，目标章节加载完成后再释放，降低 WebView 重载带来的空白闪烁。
  - EPUB 翻页动画的进出场透明度统一保持不变，并为 WebView 设置阅读背景色，减少动画中的灰屏感。

### 🧭 窗口与主页布局 (Window & Main Menu)

- **新增主窗口布局状态发布**
  > 应用会记录主窗口尺寸、窗口状态和自由窗口模式变化，让页面能跟随系统窗口实时调整。
  - `WindowManager` 新增主窗口尺寸、状态完成变化和自由窗口模式监听，并将布局快照写入 `AppStorage`。
  - 窗口变化会同步刷新系统栏高度缓存，减少横竖屏、自由窗口和最大化切换后的安全区误差。
  - 监听器在窗口状态监控解除时同步清理，避免重复订阅和残留定时器。

- **修正主页底栏响应式刷新**
  > 主页底部导航会跟随窗口变化重新计算布局，减少悬浮底栏位置错乱。
  - `MainMenuPage` 监听窗口布局变化信号，延迟同步主视口宽高并刷新响应式参数。
  - 底栏切换到浮层模式时会重新计算位移距离、重置滚动状态并强制重建 tab 控制器。
  - 页面退出时会清理窗口布局刷新定时器，避免离开主页后继续触发布局更新。

### 🛡 兼容性与稳定性 (Compatibility & Reliability)

- **自动规避模拟器 ReaderKit 限制**
  > 在模拟器环境下会主动关闭系统 ReaderKit 能力，优先避免引导后进入不可用解析链路。
  - 欢迎引导页启动时会初始化 ReaderKit 运行时门禁，并检测是否被当前环境强制禁用。
  - 若模拟器环境仍开启 ReaderKit，会自动写回设置、同步 `AppStorage`，并通过 Toast 提示处理结果。
  - 相关异常会进入统一日志，方便区分 ReaderKit 平台限制和普通 EPUB 解析失败。

- **增强文件访问容错**
  > 文件列表读取前会先确认目标是目录，减少异常路径导致的解析噪音。
  - `SafeFileUtils.listFileSync` 增加目录状态检查，普通文件、空路径或不可访问路径会直接返回空列表。
  - EPUB OPF 探测、嵌套目录扫描和封面候选路径解析会复用这层保护，降低坏包或旧缓存带来的失败概率。
  - OPF、spine 和封面识别日志补充关键路径与缺失资源样本，排查问题更直接。

### 🔌 图源与依赖同步 (Sources & Dependencies)

- **同步扩展仓库与图源修复**
  > 图源子仓库已推进到新索引，包含大量站点新增、域名更新、选择器修复和页面解析适配。
  - `extensions-source` 更新到最新提交区间，覆盖 Comicaso、MangaK、Manhuarm、CodeArc、Yomu Comics、KuroMangas 等多项修复与新增。
  - 多个图源更新了解密、分页、章节列表、搜索、封面、筛选器、限流和失效源移除逻辑。
  - 拷贝漫画扩展说明补充 Ko-fi 与爱发电支持入口，便于维护者信息展示。

- **保留本地原生依赖构建状态**
  > AVIF Windows 构建依赖目录包含本地构建缓存和 zlib 状态变化，后续排查原生图片格式构建时可继续沿用当前现场。
  - `aom`、`zlib` 依赖目录记录了本地 `build_arm64-v8a` 构建输出状态。
  - `zlib` 当前工作区存在 `zconf.h` 变化，用于反映本轮未提交文件中的底层依赖现场。
  - 本次变更未把这些缓存写入应用逻辑，避免影响 EPUB 阅读器与图源运行路径。
