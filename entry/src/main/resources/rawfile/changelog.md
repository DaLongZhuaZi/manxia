# 更新日志

## v0.1.0 (104702303)
- 此版本仅有API23软件包

#### 新功能
- 漫画阅读器新增双页-上下阅读模式
- 漫画阅读器单页模式支持横屏自动切换双页显示，可切换锁定模式
- 漫画、电子书、小说阅读器支持锁定屏幕方向，不再与系统同步旋转

#### 优化与修复
- 图源详情页、统一详情页、全局搜索页新增加载态UI，提高加载速度
- 全局搜索页，图源无法搜索问题修复

- 听书功能尚不完善
- Suwayomi功能不完整
- Komga功能不完善
- 备份与恢复功能存在多个未知问题，需要继续优化
