# 📢 更新日志

> 感谢您使用漫匣！以下是最新版本的更新内容。

## 🚀 v0.1.4 `(105402300)`

### 📄 PDF 原生阅读与导入 (Native PDF Reading & Import)

- **原生 PDF 导入流程**
  > 导入 PDF 默认以原生方式阅读并保留原文件能力，同时保留图片化兼容路径。
  - 导入对话框新增「原生阅读（推荐）/ 图片化（兼容）」阅读方式选择；电子书选择器支持直接选择 `.pdf`。
  - 原生模式改为单弹窗导入：复制工作副本 → 解析 → 用用户确认的元数据入库 → 后台构建文本索引，不再连续弹出两个确认框。
  - 修复文件名时间戳前缀导致的「随机标题」问题，并以用户确认的标题/作者/简介覆盖文件名推导结果。
  - 修复 PDF 封面提取失败（把封面目录当文件写入导致的 `Invalid fd`），并对封面路径做了目录防御；PDF 默认取首页作为封面。
  - PDF 解析改用 `getMetadata()` 回填标题、作者、主题、关键词、生产者等元数据，并在解析后释放文档。

- **PDF 阅读器功能对齐**
  > 阅读器设置统一走标准面板，PDF 专属限制显式告知，不再出现「点了没反应」。
  - PDF 设置统一复用电子书阅读设置面板；面板新增固定版式标记，对 PDF 明确标注行高、字体粗细、字体族、字体颜色由 PDF 自身决定，字号以页面缩放呈现。
  - 阅读设置逐项按 API 落地：字号→页面缩放、页边距→页面间距、翻页模式→显示方向与连续滚动、阅读主题与亮度→页面叠加底色。
  - 底栏新增「搜索」入口，目录改为展示 PDF 结构化大纲；有结构化大纲时不再同时显示纯页面目录。
  - 底部进度条支持点击/拖动直接跳页；全文搜索不再自动跳转，只有点击「上一处 / 下一处」才跳转。
  - 清理「更多」菜单中与底栏重复的 PDF 目录与全文搜索入口，并移除自造的显示面板与悬浮入口。

- **PDF 全文检索与文本索引**
  > 中文检索优先走 PDF Kit 视图级检索，未命中时用自建逐页文本索引兜底定位。
  - 新增 PDF 文本索引服务：逐页抽取文本并落盘，支持中文子串检索；扫描件（无文本层）自动识别并跳过，避免无意义索引。
  - 检索使用引擎的 `searchKey` 统计命中数，配合 `setSearchIndex` 逐条跳转；检索后恢复用户原来的页码，避免搜索把画面带走。

### 🧩 阅读器 UI 与交互 (Reader UI & Interaction)

- **工具栏与顶栏文字提示**
  > 图标按钮补上文字说明，并可在阅读设置里一键开关。
  - 新增统一的阅读器工具栏按钮组件，工具栏/顶栏按钮支持「图标 + 文字」，覆盖漫画、小说、文本、EPUB、图集等阅读器。
  - 阅读设置子页面新增开关，默认开启，切换后已打开的阅读器实时生效。
  - 修复按钮回调被私有修饰符限制导致点击无效的回归问题。

- **漫画自动阅读模式与提示时机**
  > 超长图/超宽图首次阅读时自动切换到更合适的显示方式，提示不再打扰阅读。
  - 漫画首次阅读时按页面尺寸自动切换条漫/宽图横屏模式，并记录已应用状态避免重复切换。
  - 统一交互提示的触发时机与优先级，避免与工具栏、页码指示器抢占同一时刻。

- **方向锁定统一**
  > 全局锁定屏幕方向后，阅读器不再被陀螺仪带走，并在设置中明确说明规则。
  - 方向锁定管理下沉到核心模块并统一为窗口级请求栈。
  - 阅读器按作用域解析是否受全局锁定影响，全局设置页补充规则说明。

### 📚 电子书与详情页 (E-Books & Details)

- **详情页支持分享原文件**
  > 电子书与 PDF 也能像其它内容一样从详情页直接分享原文件。
  - 电子书详情页新增「分享」入口，基于导入后的工作副本分享，不触碰用户外部原文件。
  - 按扩展名映射分享类型（PDF / EPUB / MOBI / AZW / AZW3 / TXT），内置电子书与文件缺失均有提示兜底。

### 🔤 内置字体 (Built-in Fonts)

- **得意黑（Smiley Sans）内置可用**
  > 字体随包提供，用户无需导入即可在字体管理和各阅读器中选择使用。
  - 字体资源迁入标准 `rawfile/fonts` 目录，并在字体管理器中登记为内置字体：首次启动幂等落地到沙箱、自动注册到系统，后续可直接选用。
  - 字体管理页对内置字体显示「内置」标记且不提供删除；用户自行导入的字体仍可正常删除。
  - 应用界面、小说、电子书（含 EPUB 阅读器）均直接可用；PDF 因固定版式不支持更换字体。

### 🔄 跨端接续与阅读体验 (Cross-Device Continuation)

- **接续阅读：仅阅读缓存 / 导入书库两种模式**
  > 换设备接着看，既能只带阅读进度与缓存，也能把书真正导入对方书库。
  - 新增两种接续模式：仅阅读缓存（只同步阅读进度与页面缓存，轻量）与导入书库（连书与元数据一起导入对方书库）。
  - 新增版本化传输清单、文件校验与缓存历史：接续记录可追溯，损坏或不完整的传输会被识别并拦截。
  - 新增接续阅读设置页面，集中管理接续开关、接续方式与接续缓存。
  - 修复 TXT、电子书、本地漫画与在线漫画的打包、恢复、导入及阅读进度处理；导入提交后静默刷新书库，无需手动下拉。

- **接续封面与遥控器修复**
  > 书架不再长期停在占位图，遥控返回不再白屏。
  - 修复接续漫画封面路径传递与在线封面缓存复用，避免书架持续显示占位图。
  - 修复独立遥控器返回后页面空白的问题，返回时正确恢复源端阅读器。

- **漫画显示比例**
  > 除了适应屏幕宽度，还能按高度或原始比例显示。
  - 漫画阅读器新增适宽、适高、原始比例三种布局，按页面尺寸选择更合适的显示方式。

### 🛡️ 权限合规 (Permission Compliance)

- **「设备发现和连接」改为可选能力**
  > 不授权也能照常使用全部功能，接续入口只提示不可用，不弹窗、不自动退出。
  - 该权限拆分为独立开关；未授权时应用其它功能完全不受影响，不会自动退出或反复弹窗。
  - 接续场景、接续阅读设置页与启动引导页在未授权时给出明确的功能不可用说明。
  - 权限申请只在用户主动触发时发起，启动与阅读过程仅做静默状态检查。

### 🖼️ 远端图源阅读修复 (Remote Source Readers)

- **漫画 AVIF 图片接入原生解码**
  > 部分图源直接返回 AVIF，系统解码器不支持，此前整章都是空白。
  - 图片加载管线接入已有的 Native libavif 解码器：内容嗅探为 AVIF 时走原生解码，失败再回退系统解码器。
  - 覆盖网络下载、本地文件、磁盘缓存三条解码路径；解码失败不再触发无意义的网络重试。

- **Komga 阅读链路修复**
  > 取页慢、重复下载、失败原因不可见，这次一起收口。
  - 新增实例协议自适应：首次请求前探测实际可用协议（优先 https），成功后写回实例配置，后续直接使用同一协议，不再依赖服务器跳转。
  - 取页拆成「用户可见页 / 后台预加载」两条互不干扰的通道，并为预加载设置积压上限，可见页不会再被预加载堵在队列里。
  - 单页失败后进入 30 秒抑制窗口，避免每次翻页都重新拉取同一张取不到的图；同时消除同一页的重复下载。
  - 网络错误不再显示为 `[object Object]`，改为输出错误码与原因，并对 401/403、重定向、404 给出成因提示。
  - 主菜单 Komga 系列封面改用完整显示，不再被裁掉上下约四分之一。

- **加载阶段可见**
  > 取页要几十秒，界面不再只有一句「加载中...」。
  - 新增加载阶段上报（排队 / 取页 / 解码 / 失败），阅读器占位区实时显示当前阶段与已等待时长，失败时直接给出原因。
