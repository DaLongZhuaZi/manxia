# 📢 更新日志

> 感谢您使用漫匣！以下是最新版本的更新内容。

## 🚀 v0.1.2 `(104902300)`

### 📥 在线漫画缓存与下载 (Online Manga Cache & Downloads)

- **修复 Download 目录授权与缓存管理衔接**
  > 已连接的 Download 目录现在会正确进入在线漫画缓存流程。
  - Download 同步页、同步管理器与缓存下载管理器会共享已授权目录状态，避免已经连接目录后仍提示需要重新授权。
  - 已保存的 Download 路径会在下次进入时自动恢复，并在目录失效时提示重新连接。
  - 在线漫画下载前会刷新最新缓存状态，已缓存章节会自动跳过，不再重复创建下载任务。

- **优化缓存章节对话框**
  > 刚缓存完成的章节会自动从可下载列表中排除。
  - 缓存完成、部分归档保存完成后会立即刷新详情页缓存状态和下载对话框选择状态。
  - 批量选择会只统计仍可缓存的章节，已缓存章节置灰并禁止重复勾选。
  - 进度统计支持按本次创建的任务聚合，批量缓存时的当前章节、已完成数和失败数更准确。

- **增强在线漫画页表与归档识别**
  > 下载链路会优先复用已有页表，并在必要时回退图源拉取。
  - 在线漫画缓存页表会保存请求头，后续下载可复用已解析出的图片链接和 Header。
  - 图源预取页表、数据库页表和 WebView 图源拉取之间增加兜底顺序，减少空页表导致的缓存失败。
  - 旧版本归档即使缺少页表，也能通过 CBZ 文件存在状态正确识别为已缓存章节。
  - 缓存进度改为按章节完成度展示，页数未知时不会再误显示为 0%。

### ⚡ 已下载在线漫画阅读 (Downloaded Online Manga Reading)

- **新增本地首图优先加载**
  > 已缓存到本地的在线漫画会优先从 CBZ 解压页显示首图。
  - `OnlineDownloaded` 命中本地 CBZ 时，阅读器会先解析本地 `LOCAL` 页面并尽快提交首屏。
  - 首图显示后再自动继续 WebView/图源完整预热，不再把隐藏 WebView URL 获取阻塞在首图前。
  - 本地归档缺失、空归档或包含网络占位页时仍回退原完整初始化流程，避免破坏未下载章节能力。

- **完整接入阅读监控**
  > 首图快速通道和延迟完整预热都能在监控中看清楚。
  - 新增 `warmupState`、`archivePath`、`extractDir`、`reusedExtract`、`pageCount`、`networkPageCount` 等缓存快照字段。
  - 首图提交、延迟预热开始、预热成功和失败降级都会写入 `MangaReadFlowMonitor`。
  - 首屏前降低本地 PixelMap 预加载范围，完整预热就绪后再恢复图源配置的预加载策略。

- **优化 CBZ 解压复用**
  > 已解压过的在线漫画归档会尽量复用读取目录。
  - `OnlineMangaArchiveService` 会记录本次是否复用已有解压目录，避免重复解压带来的等待。
  - 阅读器缓存监控会展示归档与解压目录状态，便于定位本地缓存是否真正命中。

### 📚 章节排序与缓存迁移 (Chapter Ordering)

- **新增统一详情页章节排序编辑**
  > 漫画、小说和电子书章节可在详情页调整显示顺序。
  - 章节列表新增排序编辑模式，支持移动章节、保存自定义顺序、恢复来源顺序。
  - 排序保存期间会暂停阅读、刷新、下载等冲突操作，避免状态错乱。
  - 自定义顺序会持久化到数据库，并在重新进入详情页、刷新内容后继续生效。

- **同步阅读进度与缓存索引**
  > 调整章节顺序后，相关缓存会跟随新索引迁移。
  - 阅读进度会按章节稳定标识重映射，减少排序后跳到错误章节的情况。
  - 小说正文缓存、本地朗读音频缓存和远程听书缓存会按章节索引迁移。
  - 详情页保存排序后会刷新缓存状态和朗读缓存状态，确保页面显示与实际缓存一致。

### 🔎 全局搜索体验 (Global Search)

- **优化搜索结果展示与缓存**
  > 重复搜索同一条件时响应更快，结果排序更贴近关键词。
  - 完整搜索结果新增运行期缓存，筛选条件一致时可直接恢复结果。
  - 搜索结束后会隐藏失败或无结果的来源分组，并按标题、作者、简介匹配度重排分组。
  - 在线来源搜索新增进度状态，便于确认当前搜索完成度。

- **增强搜索历史与展开布局**
  > 搜索历史更稳定，结果展开视图更适合浏览。
  - 搜索历史会同时写入运行期状态和持久化偏好，重启后仍可恢复。
  - 历史关键词会去重、裁剪空白并限制数量，避免重复条目堆积。
  - 结果展开区域增加固定网格尺寸，减少展开/收起时的布局跳动。

### 🧭 图源引擎与 WebView (Source Engine & WebView)

- **修复 API 分页请求污染**
  > 分页加载章节和图片列表时不再直接修改原始图源配置。
  - API 分页请求会为每一页创建独立 action，避免页码参数残留影响后续请求。
  - 图源 action 克隆补齐 headers、body、extract、pagination、validation、condition 分支等字段。
  - 页面列表请求增加串行队列，降低同一图源并发拉取页表时的上下文互相覆盖风险。

### 🛠 修复与体验优化 (Fixes & Improvements)

- **降低独立阅读器关闭阶段窗口误报**
  > 关闭独立漫画阅读器时的窗口销毁竞争会被识别为生命周期收尾。
  - `getLastWindow`、`getWindowAvoidArea`、`setWindowPrivacyMode` 在 detach/destroy 阶段遇到 `1300002` 时会降级记录。
  - 系统栏高度刷新遇到失效窗口时会跳过，不再写入 0 或覆盖已有安全区高度。
  - 主窗口仍有效时，亮度、常亮、隐私窗口模式和系统栏恢复行为保持不变。

- **优化内容追踪卡片状态**
  > 内容追踪卡片更清晰地区分摘要和详情。
  - 卡片支持主体和更多信息的独立展开状态。
  - 自动创建追踪规则后会保留当前会话标记，切换内容时自动重置。

- **修正本地章节查询排序**
  > 本地漫画章节读取统一按章节序号排序。
  - 本地章节查询从旧的标题/索引混合排序调整为 `chapterNumber ASC`，减少章节顺序异常。
