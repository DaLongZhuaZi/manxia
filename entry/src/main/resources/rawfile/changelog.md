# 更新日志

## v0.0.7 (1028027)

#### 新功能
- 新增错误日志自动收集、错误信息页面等，方便反馈具体的问题
- 新增APP后台运行逻辑（不需要权限），可在书源校验、内容下载时后台长时运行，运行完成后自动关闭该逻辑
- 详情页新增快捷搜索功能，可对标题、作者、标签、简介等任何内容触发全局搜索
- 详情页新增相关推荐功能
- 新增帮助中心页面
- 书库-书架视图（书库页面右上角）新增“动态书架”，可根据规则自动收集内容纳入到书架内
- NSFW 功能完善，支持所有内容类型与动态书架，以及源级 NSFW 作用域，NSFW 图源/书源的内容将会自动打上NSFW标签（可单独关闭）

#### 优化
- 卷曲翻页动画细节优化，动画阴影更真实，脱手后更加自然，回弹更顺滑
- 主页面的书源、Suwayomi支持内容缓存，冷启动时会先加载缓存数据再静默刷新
- 禁止再跳过引导流程
- 阅读器的打开/关闭动画流程优化，避免交互锁死
- 批量导入流程优化、识别逻辑优化，压缩包/文件夹可以同时混合识别

#### 修复
- 备份与恢复功能及相关的启动流程优化，避免频繁出现ANR闪退
- 哔咔漫画阅读限制的问题
- 外部文件打开逻辑修复

#### 仍然存在的问题
- Suwayomi功能不完整
- BatchMangaImportDialog存在UI不同步问题
