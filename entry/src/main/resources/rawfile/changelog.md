# 📢 更新日志

> 感谢您使用漫匣！以下是最新版本的更新内容。

## 🚀 v0.1.2 `(104902304)`

### 🧩 图源稳定身份与重导兼容 (Source Identity & Compatibility)

- **改用稳定 pkg 身份识别 WebView 图源**
  > 图源删除后重新导入、更新或迁移时，不再只依赖容易变化的数字 sourceId。
  - 新增 `SourceIdentity`，用 sourceId、pkg、版本和配置哈希生成运行时签名。
  - `WebViewSourceManager` 优先按 pkg 建立 `MangaSourceEngine` 缓存，配置签名变化时会自动重建引擎。
  - 图源导入和更新要求存在 `metadata.id`，用于建立稳定 pkg 身份并避免后续记录漂移。

- **修复在线漫画、收藏与章节缓存回接**
  > 已收藏、已缓存或已阅读的在线漫画，在图源重导后更容易回到同一条记录。
  - 保存在线漫画时优先按 pkg + externalId 复用旧内部 ID，再回退 sourceId 和旧 sourceName。
  - 新增图源兼容修复服务，导入/更新后会回填 sourcePkg、合并重复在线漫画，并修复章节缓存状态。
  - 漫画详情加载、搜索执行器、阅读身份解析和收藏状态同步继续传递 sourcePkg，降低章节跳转和收藏识别错配。

- **清理旧运行缓存，避免继续使用过期配置**
  > 图源配置变化后，搜索、详情和阅读链路会尽量使用最新配置重新初始化。
  - 图源更新会清理执行器缓存、WebView 引擎缓存、sourceId/name/pkg 映射和图源数据缓存。
  - 数据库版本升级到 17，新增 online comic 与章节缓存的 pkg 查询索引。
  - WebView script action 的 timeout 会被配置克隆保留下来，避免编辑或复制配置后丢失超时设置。

### 🧪 图源自动巡检与报告 (Source Auto Check)

- **新增可选择范围的图源自动巡检**
  > 图源可以自动跑已配置 workflow，减少手动逐项点测。
  - 巡检前可选择本次检查范围，默认优先覆盖热门、最新和搜索等外部入口。
  - 会按源站逐项运行 workflow 预览，记录成功/失败、评分、耗时、摘要和错误详情。
  - 多源站图源会生成推荐源站，推荐结果可以一键应用到当前草稿，保存后生效。

- **巡检支持后台任务、通知和悬浮球**
  > 关闭页面或切到其他功能时，自动巡检仍能继续运行并保留进度。
  - 巡检任务接入后台任务管理，支持进度通知、完成/失败通知和通知点击回到报告页。
  - 任务悬浮球支持查看巡检进度、打开对应报告和停止等待中或运行中的任务。
  - 取消任务会同步刷新悬浮球、通知和巡检报告状态，避免后台任务残留。

- **保存巡检历史并可恢复报告**
  > 每个图源会保留最近巡检记录，便于对比不同版本或不同源站的表现。
  - 巡检记录写入本地偏好存储，最多保留最近 80 条索引记录。
  - 编辑器入口可查看历史巡检、展开站点明细、查看推荐源站和本次检查范围。
  - 通过通知或悬浮球进入时，会优先恢复指定 taskId 的实时快照或历史报告。

### 📦 本地图源导入与扩展维护 (Local Sources & Extensions)

- **本地图源导入增加预览确认**
  > 批量导入本地 source.json 前可以先看到每个图源是否可用、是新增还是更新。
  - 文件选择后会解析多个本地图源，显示名称、版本、描述、升级/降级/同版本状态和不可用原因。
  - 确认导入后逐个安装并显示进度、当前图源、成功/失败状态和最终汇总。
  - 导入完成且全部成功时会自动关闭弹窗，失败时保留明细方便重试或排查。

- **同步图源扩展索引和维护信息**
  > 扩展仓库内容跟随上游和自维护源更新，减少导入后还要手动修补的情况。
  - CopyManga 索引更新到 1.4.82，VomicMHPlus 更新到 1.4.3，并新增 ManwaYuPlus / 漫蛙2+。
  - `extensions-source` 与 `manxia-extensions-source` 同步最新提交，其中 NoyAcg 迁移到 v4 API 并更新 CDN。
  - 清理 copymanga-copy20 中旧 APK 发布包，降低仓库冗余体积。

### 🛠 图源编辑、详情页与任务入口 (Editor & Detail)

- **补齐图源编辑和自动检查入口**
  > 图源出问题时，可以更快从当前页面进入排查流程。
  - 图源管理长按菜单新增“自动检查”，会直接打开交互式编辑器并进入巡检流程。
  - 图源详情页失败和空结果状态同时提供“重试”和“自动检查图源”。
  - 图源详情页诊断按钮图标改为听诊器样式，和普通搜索入口区分。

- **增强通知点击后的页面恢复**
  > 从系统通知进入应用时，会恢复到对应的图源巡检报告。
  - `EntryAbility` 会识别巡检通知参数并记录到 AppStorage。
  - 主菜单接到通知触发后，会补齐 sourceId、sourceName、sourcePkg、initialUrl 和 taskId 后跳转。
  - 不认识的通知路由会被忽略，避免误跳到非预期页面。

### 🖥 详情页、横屏与阅读小修 (Detail & Reader Polish)

- **优化统一详情页横屏布局**
  > 横屏时章节列表、缓存信息和阅读按钮不再互相挤占空间。
  - 右侧顶部信息区改为高度受限并可独立滚动，章节列表在展开时保留最低可用高度。
  - 阅读和听书按钮改为右下角悬浮操作组，不再占用章节列表高度。
  - 横屏高度会记录到响应式状态，用于更准确地计算可用布局空间。

- **补齐阅读和图源交互细节**
  > 一些失败态和辅助操作的下一步更明确。
  - 漫画阅读器章节数据为空时，按钮文案从“返回”改为“重试”。
  - 书源型图源卡片继续保持搜索入口，并为 Legado 漫画书源提供复制基础 URL 操作。
  - 图源运行配置失效时会清空对应 WebView 数据缓存，减少旧详情和旧章节列表干扰。
