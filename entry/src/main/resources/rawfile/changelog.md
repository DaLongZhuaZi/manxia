# 📢 更新日志

> 感谢您使用漫匣！以下是最新版本的更新内容。

## 🚀 v0.1.2 `(104902306)`

### 🪟 弹窗与沉浸式界面 (Dialogs & Immersive UI)

- **统一常用弹窗的玻璃卡片样式**
  > 书架、下载、换源、章节排序、分享、听书缓存等弹窗现在更像同一套界面。
  - `SourceDialogScaffold` 默认使用设置页精选卡片表面，统一圆角、阴影、边框宽度和 24px 内容边距。
  - 加入/替换书架、缓存确认、封面生成、重复检测、分享链接、下载和章节排序等弹窗同步使用统一外观。
  - 多个弹窗补齐打开/关闭动画，关闭时先播放淡出再隐藏，减少突兀闪烁。

- **重整小说设置、听书缓存和更新提醒弹窗**
  > 复杂设置面板改成更稳定的弹窗结构，内容多时也能保持按钮和标题可见。
  - 小说/电子书设置弹窗使用分段标签和滚动内容区，未应用修改时显示统一确认弹窗。
  - 听书缓存弹窗保留“缓存、管理、设置”三段入口，预缓存状态、进度和详情显示更紧凑。
  - 更新提醒弹窗改为“基础、筛选、操作”分页，说明卡片与底部操作区保持固定节奏。

- **优化设置页沉浸式标题栏**
  > 顶部玻璃标题栏和页面内容之间的过渡更柔和。
  - 标题栏新增边缘淡化层，降低顶部材质与正文之间的硬边界。
  - 背景、渐变和反光层改为透明命中，不再影响下层交互。
  - 标题栏高度、安全区 padding 和内容顶部间距继续由 `SettingsPageTitleBarManager` 统一计算。

### 📦 图源仓库同步与本地导入 (Source Repository)

- **同步完成后展示新增、更新和废弃摘要**
  > 图源仓库同步不再只给一行结果，可以直接看到本次变化了哪些图源。
  - `SyncResult` 新增 added / updated / deprecated 明细，主菜单同步弹窗会按分类展示变化数量。
  - 同步摘要支持展开查看图源名称、pkg、版本变化和最多 4 条图源 changelog。
  - 同步日志改为可展开/收起，完成后默认展示摘要，失败时保留日志方便排查。

- **同步时处理远端已移除图源**
  > 仓库索引会把远端不再存在的图源标为废弃，而不是继续混在当前索引里。
  - 同步时会对比远端 pkg 集合，移除当前索引中已废弃的条目。
  - 结果文案会同时统计新增、更新和废弃数量。
  - 图源配置写入改用精确字符串写入，降低 JSON 被截断或编码异常的风险。

- **本地图源导入后覆盖保存仓库文件**
  > 从本地导入或更新图源后，运行时数据库和本地仓库文件会保持一致。
  - 导入成功后会把 source.json 内容保存到本地仓库目录对应 pkg 文件。
  - 如果图源已导入但文件覆盖失败，会在导入列表中显示失败原因，方便重新处理。
  - 新建书架弹窗改为 CustomDialogController 打开，样式与图源导入弹窗保持一致。

### 🖼 图片加载与 WebView 图源配置 (Images & WebView Sources)

- **适配漫画狗图片和封面请求头**
  > 需要特定来源头的图片站点加载更稳。
  - 漫画狗图片请求会自动补齐 `Referer: https://dogemanga.com/` 和对应 `Origin`。
  - 在线图片加载器会为漫画狗图片使用兼容 UA，避免默认 UA 触发站点拒绝。
  - 封面缓存下载也同步补齐漫画狗请求头，降低封面可读但缓存失败的概率。

- **保留图源页面级请求头和脚本变量配置**
  > 图源 workflow 生成的图片页信息可以携带更多站点所需上下文。
  - `MangaSourceEngine` 解析页面时会保留 item.requestHeaders，并与 `X-Image-Ticket` 一起写入页面请求头。
  - `ScriptAction` 补齐 `saveAs` 类型和克隆逻辑，编辑或复制 workflow 时不会丢失脚本结果变量名。
  - 隐藏 WebView 预热源站上下文失败时，阅读器会记录警告并继续交给图源 workflow 自己导航。

### 🧭 图源识别、搜索与维护 (Source Metadata & Maintenance)

- **网络代理标识解析更宽容**
  > 图源 metadata 中的网络代理字段不再只识别布尔 true。
  - `metadata.Internet` 支持 boolean、number 和 string，`true`、`1`、`yes` 都会识别为需要代理。
  - 图源列表映射数据库布尔值时也支持 `true`、`1`、`yes` 等形式。
  - 全局搜索页中的图源标识文案改为“网络代理标识”，语义更准确。

- **同步自维护扩展源**
  > 自维护图源仓库继续跟进可用来源。
  - `manxia-extensions-source` 更新到新增多个中文漫画/图库图源的版本。
  - AVIF 本地依赖目录状态保持在工作区，便于后续原生图片能力排查。
  - 阅读器和图源相关日志补充容错说明，遇到预热无法确认时不再直接中断阅读链路。
