# 版本号规范说明
- 10XX021表示该版本为API 21编译的软件包，10XX023表示该版本为API 23编译的软件包，可以根据自己的系统版本进行安装
- 不一定每个版本都会上传两个不同API的软件包
- 会在绝大多数设备都推送API 23正式版之后取消对API 21、22的支持
