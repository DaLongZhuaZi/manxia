# 更新日志

## v0.0.9 (104602305)
- 此版本仅有API23软件包

#### 新功能
- 在线内容新增APP链接功能，可精准跳转漫匣的APP内页面
  使用方法：在统一详情页-工具栏里面，点击“分享”按钮打开对话框，选择APP内链（需要手动输入），或网页链接（可直接分享到各APP，在浏览器打开后可以直接跳转到漫匣内的页面）
- 本地内容新增本地分享功能，在统一详情页-工具栏里面，点击“分享”按钮即可触发系统文件分享功能
- 主题设置页面新增HdsTab效果自定义，修改后需重启APP生效

#### 优化与修复
- HdsTab（在主页面设置当中切换）默认显示效果优化

#### 仍然存在的问题

- Suwayomi功能不完整
- Komga功能不完善
- 备份与恢复功能存在多个未知问题，需要继续优化
