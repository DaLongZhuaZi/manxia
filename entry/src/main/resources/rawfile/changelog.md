# 更新日志

## v0.0.7 (1031027)

#### 新功能
- 底栏显示逻辑优化，针对手机设备（包括折叠状态的折叠屏），底栏会在旋转时自动切换到侧边
- 新增桌面图标快捷方式，可以快速打开阅读报告、全局搜索、继续阅读（打开上一次阅读内容的详情页），或者长按快捷方式添加到桌面

#### 优化
- 首页-最近阅读封面图片背景圆角修复
- 图源仓库导入添加连通性检测，自动使用代理站加速访问
- 漫画阅读器对已缓存的在线漫画加载流程优化

#### 修复
- 书源页面缓存逻辑修复
- Suwayomi封面图片不显示的问题
