# 📢 更新日志

> 感谢您使用漫匣！以下是最新版本的更新内容。

## 🚀 v0.1.2 `(104902304)`

### 📖 阅读器与方向锁定 (Reader Orientation & Settings)

- **对齐小说、电子书与漫画阅读器的方向锁定**
  > 阅读器方向锁定不再只服务于漫画链路，小说、本地电子书、在线电子书和 Markdown 阅读也能使用一致的入口与逻辑。
  - 阅读设置页新增电子书与文本阅读的“锁定方向”全局开关，并会同步写入运行时设置。
  - 电子书阅读页会按当前格式区分 ReaderKit、文本、Markdown 与图片页阅读器，分别同步屏幕方向锁定状态。
  - 小说/电子书阅读设置面板补齐方向锁定展示与保存，和漫画阅读器的操作语义保持一致。

- **稳定阅读器浮层打开时的顶部信息栏**
  > 打开目录、设置、书籍信息等浮层时，顶部信息栏不再因为安全区高度反复计算而明显抽动。
  - 电子书阅读页统一使用稳定的顶部工具栏高度与安全区 inset，减少浮层开关时的布局抖动。
  - Markdown、文本和图片页阅读模式会按自身链路处理工具栏显隐，避免把 ReaderKit 的切换逻辑套到非 WebView 阅读器上。
  - 漫画阅读器传参补齐网络请求头兜底，降低阅读器状态刷新时的空值干扰。

- **补全阅读设置备份恢复**
  > 阅读习惯可以随备份迁移，恢复后不再只还原书库和进度。
  - 普通备份与增强备份都会导出电子书单书阅读设置，包括字号、页边距、背景、翻页、常亮和方向锁定等字段。
  - 全局电子书/文本方向锁定设置会进入 reader settings，并在恢复后刷新设置管理器与 AppStorage。
  - 备份模型改为显式 ArkTS 接口，减少未类型化对象字面量带来的编译风险。

### 📝 Markdown 阅读体验 (Markdown Reader)

- **将 Markdown 从纯文本展示升级为专用渲染**
  > Markdown 内容会按文档结构美化显示，而不是简单铺成普通文本。
  - 新增 Markdown 阅读控制器状态，支持标题、列表、代码块、链接、阅读样式和主题联动。
  - `markdown_preview.html` 补充阅读布局与渲染脚本，进入内置使用手册时会在首帧后自动完成渲染。
  - Markdown 阅读进度会记录章节进度、页码和整体进度，右下角页码不再依赖翻页后才校正。

- **修正长 Markdown 页面跳转**
  > 很长的 Markdown 页面可以准确跳到目录项、锚点和小分点。
  - 同章锚点跳转会直接滚动到目标 heading，跨章节跳转会先切换章节再执行锚点恢复。
  - 普通目录跳转会重置到章节开头，避免沿用旧的分页阅读位置。
  - Markdown 链接点击会被阅读器接管并保存进度，外部链接保持拦截日志，避免误触离开阅读环境。

### 🧰 图源诊断与交互式编辑器 (Source Diagnostics & Editor)

- **新增结构化图源诊断链路**
  > 图源失败时可以看到具体是哪个 workflow、action、选择器或脚本出了问题。
  - `MangaSourceEngine` 与 `MangaSourceActionEngine` 会生成 traceId，并记录 workflow 名称、action 序号、当前 URL、耗时和诊断事件。
  - `ActionResult` / `EngineResult` 补充诊断字段，错误文案可以定位到类似“搜索 workflow 第 3 步 extract 失败”。
  - 新增图源诊断中心页面，可查看最近 trace、运行时间线、事件日志和导出文本。

- **新增交互式图源编辑器**
  > 用户可以在可见 ArkWeb 页面上点选 DOM 生成规则，不必直接编辑 source.json 文件。
  - 新增 `InteractiveSourceEditorService`、`SourceRuleGenerator`、`SourceDraftStore`、`SourceConfigValidator` 和编辑器类型定义。
  - 编辑器支持选择搜索、详情、章节、图片列表等任务，输入测试 URL 后打开可操作网页并注入 DOM 选择脚本。
  - 点选结果会生成 CSS selector / XPath / 属性提取建议，并实时预览匹配数量、提取样本和 workflow 结构。

- **补齐图源编辑入口与保存模式**
  > 图源管理页和详情页可以直接进入诊断或编辑，修改默认走更稳妥的草稿链路。
  - 图源管理列表新增诊断与编辑按钮，主导航和页面注册表补齐 `SourceDiagnosticPage` 与 `SourceInteractiveEditorPage`。
  - 编辑器支持本地派生副本、覆盖已安装图源和导出扩展包等保存模式，并在保存前做配置校验。
  - 诊断日志会做敏感字段脱敏，避免 Cookie、Authorization、token 等内容直接进入导出文本。

### 🪟 悬浮检查器与窗口交互 (Floating Inspector)

- **用应用内小窗承载 DOM 与工作流检查**
  > 参考局域网传书小窗实现，DOM 详情和选择状态从主页面中拆出，网页操作区更大。
  - `WindowManager` 扩展应用内小窗路由，新增图源编辑器悬浮检查器页面并注册到 `main_pages.json`。
  - 主编辑页离开时会销毁检查器，小窗状态通过 AppStorage 与状态管理器同步，避免页面退出后残留。
  - 主页面移除“普通/高级”模式按钮，把工作流状态、选择提示、DOM 详情和保存操作集中到检查器。

- **优化小窗拖动、状态刷新和提示文案**
  > 悬浮窗现在更像可分离工具栏，移动和刷新状态都更稳。
  - 小窗移动改为 16ms 节流并限制在屏幕范围内，减少拖动过程中的抖动。
  - 对设备不支持的小窗外观能力降级为调试日志，避免把可忽略能力差异显示成运行错误。
  - 检查结果区使用不同颜色区分正常、异常、等待和最终流程，按钮也按绿色/红色强化操作语义。
  - 提示文案放大并引导用户先翻到目标区域，再重新选择当前 workflow 需要的 DOM。

### 🖼 图源详情加载与封面展示 (Source Detail & Covers)

- **重建图源详情页加载状态流**
  > 图源详情页不再经历“空白页 -> 空白加载 -> 占位封面 -> 真封面”的多段跳。
  - 新增 `BOOTSTRAPPING`、`LOADING_EMPTY`、`SHOWING_CACHE_REFRESHING`、`READY`、`EMPTY`、`ERROR`、`PAGING` 等加载阶段。
  - 冷启动立即进入页面壳和骨架屏；已有内容时刷新不会提前清空列表，而是显示轻量刷新提示。
  - 网络失败与真实空结果分开处理，有旧内容时保留旧列表并显示错误横幅，没有内容时显示可解释错误态。

- **增加缓存快照与直达作品链路保护**
  > 有可展示数据时优先展示，链接直达作品也不会破坏图源详情页原本功能。
  - `SourceContentCache` 新增 fresh / stale / missing 快照，30 分钟内新鲜缓存直接使用，24 小时内过期缓存可先展示再后台刷新。
  - 列表、搜索、筛选和分页使用 requestToken 防止旧请求回写，新结果成功后再原子替换。
  - 通过链接直达作品时会先打开目标详情，返回后再补齐 WebView 图源列表上下文，避免影响原有直达功能。

- **修复封面本地缓存解码与智能显示**
  > 日志显示封面下载完成后，页面能正确刷新并继续使用按图片比例切换显示模式。
  - 图源详情页新增封面状态：无封面、本地加载、本地就绪、网络加载、成功和失败，卡片尺寸保持稳定。
  - 首屏封面会先批量查询本地缓存并预热，网络下载与懒加载共享状态，避免重复请求。
  - 本地封面解码改为 fd、buffer、uri 多入口兜底，使用 `desiredSize` 与 `RGBA_8888`，本地失败会回退网络加载。
  - PixelMap 写入后会刷新封面状态和比例缓存，恢复宽图/高图的智能展示逻辑。

### 🛡 兼容性、页面入口与维护 (Compatibility & Maintenance)

- **同步页面入口、版本信息和开发者应用**
  > 本次功能相关入口已经接入主导航与资源配置。
  - 应用版本号提升到 `104902303`，关于页测试邀请链接同步更新。
  - 开发者应用页新增 NGF Coder，并加入对应图标资源。
  - 图源诊断、交互式编辑器和悬浮检查器补齐页面注册，确保能通过现有导航栈打开。

- **收紧条漫与窗口相关类型**
  > 一些容易触发 ArkTS 类型问题的边界值做了显式收束。
  - 条漫相邻章节与数据规划输入从 `undefined` 改为 `null`，更符合当前空值判断方式。
  - 多个独立 Ability 页面改为显式 `LocalStorage` 入口，减少多实例页面状态串扰。
  - AVIF 本地依赖目录状态继续保留，便于后续原生图片格式构建排查，不改变应用运行逻辑。
