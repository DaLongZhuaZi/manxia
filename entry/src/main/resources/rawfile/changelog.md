# 📢 更新日志

> 感谢您使用漫匣！以下是最新版本的更新内容。

## 🚀 v0.1.3 `(105002300)`

### ⭐ 漫匣支持者计划 (Supporter Plan)

- **新增支持者计划入口与专属功能展示**
  > 在设置页可以直接了解支持者计划和可用的增强能力。
  - 设置页新增“漫匣支持者计划”入口，展示自定义主题、全局背景、后台隐私遮罩、SFW 模式、隐私书架、远程书库、字体、MD/HTML 渲染、阅读器多开和小说设置等能力。
  - 功能卡片支持查看详细说明，并可跳转到对应设置页；跳转时会沿用设置搜索定位和命中高亮。
  - 支持者状态使用本机设置保存，只影响当前设备的功能展示，不上传支付账号、密码或个人信息。

- **补充支持者计划协议页面**
  > 支持方式、权益范围和记录方式在应用内集中说明。
  - 新增支持者计划协议页面，说明自愿支持性质、支持金额、权益调整、隐私记录和争议处理规则。
  - 协议页面沿用设置页沉浸式标题栏、主题系统、全局背景和玻璃卡片样式。
  - 协议内容标注更新日期，便于后续版本维护和用户查看。

- **完善赞赏码与微信跳转流程**
  > 支持者可以更顺畅地完成赞赏和本机激活。
  - 赞赏入口文案调整为“扫码赞赏（推荐）”，明确推荐的支持方式。
  - 支持将赞赏码保存到系统图库，保存成功后自动尝试打开微信。
  - 保存失败、取消保存或微信不可用时保留明确的提示和重试路径。
  - 完成赞赏码保存并跳转后，可在本机激活支持者状态；计划也支持后续取消激活。

### 🌐 支持者名单与远程数据 (Supporter Data)

- **支持者名单改为独立数据管理**
  > 名单不再硬编码在页面中，更新内容时无需修改页面结构。
  - 新增 `SupporterDataManager` 和明确的 `SupporterRecord` 数据模型。
  - `SupportersPage` 优先读取远程缓存，缓存不可用时回退到 `rawfile` 中的本地名单。
  - About 页面进入时会触发静默刷新，支持者页面收到数据版本变化后自动重新加载。

- **增加远程路由切换与失败冷却**
  > 网络不稳定时仍尽量保持名单可读，并减少重复请求。
  - 远程名单支持主站和 GitHub 代理路由，自动记录上次可用路由。
  - 请求失败或返回无效数据时进入冷却窗口，避免连续触发同一失败路由。
  - 远程数据解析失败、网络异常或响应状态异常时保留本地缓存和本地名单作为降级结果。
  - 静默刷新按时间间隔执行，成功后更新缓存和页面数据版本，不阻塞 About 页面打开。

### 🔎 设置搜索与定位优化 (Settings Search)

- **新增更多设置项搜索结果**
  > 从支持者计划功能说明跳转设置时，可以直接定位到对应开关。
  - 新增阅读器页面多开、后台模糊遮罩、全局自定义背景和 EPUB WebView 渲染引擎搜索项。
  - 补充阅读器多开、隐私遮罩、非主页面背景、MD 渲染和 HTML 渲染等关键词。
  - 搜索结果支持记录目标页面、锚点和滚动偏移，打开设置页后自动滚动到相关位置。

- **增加设置项命中高亮**
  > 通过搜索进入设置页时，目标区域更容易被发现。
  - 页面背景模糊、阅读器多开和全局自定义背景等设置容器增加稳定 ID。
  - 命中设置会显示主题适配的背景和边框高亮，离开目标后恢复原有面板外观。
  - “非主页面全局背景”统一调整为“全局自定义背景”，与当前功能定位和搜索关键词保持一致。

### 📖 阅读器安全区与工具栏稳定性 (Reader Toolbar)

- **稳定记录漫画与小说阅读器工具栏安全区**
  > 工具栏首次显示或窗口状态变化时，顶部布局不再跟随瞬时状态反复跳动。
  - 漫画和小说阅读器新增稳定的状态栏高度缓存，在工具栏显示动画开始前捕获当前安全区。
  - 工具栏高度、顶部内边距、点击命中区域和更多菜单位置统一使用稳定高度计算。
  - 状态栏高度尚未准备好时使用项目既有默认 inset，避免出现零高度或点击区域错位。
  - 横竖屏切换、沉浸式状态变化和工具栏反复显示时，顶部玻璃栏与内容过渡更稳定。
