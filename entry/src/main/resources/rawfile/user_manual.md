欢迎使用 **漫匣**。漫匣是一款面向漫画、电子书、小说和在线内容源的综合阅读应用，目标是把“收集、整理、阅读、同步、统计”放在同一套安静、沉浸、可自定义的体验里。

## 01 快速开始与界面导航

漫匣的主界面围绕几个核心入口组织：**首页、书库、发现、图源、书源、Suwayomi、Komga、设置**。实际显示的标签会根据你的设置和功能开关有所变化。

### 首页

首页用于快速回到最近阅读的内容，也会提供常用入口：

- 最近阅读的漫画、电子书和小说。
- 小说阅读入口，支持本地小说或 Legado 书源能力。
- Suwayomi 与 Komga 的快捷卡片。
- 新用户引导、功能提示和后续推荐入口。

### 书库

书库是本地内容的主要管理位置。你可以在这里查看漫画、电子书和小说，也可以根据阅读状态、书架分类、来源、最近阅读时间等维度整理内容。

### 发现

发现页用于浏览来自在线图源、书源或远程书库的内容。它适合用来找新作品、进入来源详情、查看分类和筛选结果。

### 图源与书源

图源主要服务于漫画类在线内容；书源主要服务于小说类在线内容。漫匣通过扩展仓库、源管理和登录/调试工具来维护这些来源。

### 设置

设置页集中管理主题、全局阅读选项、备份恢复、存储清理、网络文件夹、关于应用等内容。

## 02 书库、书架与内容整理

书库是漫匣的核心。它并不只是一组文件列表，而是所有本地内容、在线收藏、阅读记录和分类整理的入口。

### 内容类型

书库支持多种内容类型：

| 类型 | 常见来源 | 主要阅读器 |
| --- | --- | --- |
| 漫画 | 本地压缩包、图片文件夹、图源下载 | 漫画阅读器 |
| 电子书 | EPUB、PDF、TXT、MD、Kindle 格式 | 电子书阅读器 |
| 小说 | 本地 TXT、书源导入、在线目录 | 小说阅读器 |

### 视图与排序

书库支持网格和列表等视图方式。你可以按名称、加入时间、最近阅读、阅读状态等方式整理内容。对于内容较多的书库，建议先按类型切换，再用筛选和搜索缩小范围。

### 书架与分类

漫匣支持将内容放入不同书架，适合按题材、来源、状态或个人习惯整理，例如：

- `正在追`
- `已完结`
- `学习资料`
- `Markdown 文档`
- `待读小说`

动态筛选书架可以根据图源、书源或内容状态自动聚合条目，适合长期维护较大的书库。

### 多选与管理

在支持的列表中，你可以进入多选模式批量处理内容，例如删除、移动、整理、缓存或导出。删除前请留意内容是否只存在于本地，避免误删未备份文件。

## 03 本地导入与网络文件夹

漫匣支持从本地文件、系统分享、网络文件夹和传输工具导入内容。

### 支持的本地内容

常见支持范围包括：

- 漫画压缩包：`zip`、`cbz`、`rar`、`cbr`、`7z` 等。
- 图片文件夹：按文件名顺序组成章节或单本漫画。
- 电子书：`txt`、`epub`、`pdf`、`md`、`mobi`、`azw`、`azw3`。
- 小说文本：本地 TXT 可进入小说阅读器或电子书阅读器链路。

### 导入建议

1. 文件名尽量保留作品名、卷号、章节号。
2. 图片页建议使用自然排序命名，例如 `001.jpg`、`002.jpg`。
3. 大型压缩包导入后，先打开检查页序是否正确。
4. Markdown 文档建议使用 UTF-8 编码，并使用标准标题层级。

### 网络文件夹

设置页中的网络文件夹能力支持连接远程目录，适合从 NAS、服务器或局域网设备导入文件。常见协议包括：

- WebDAV
- FTP
- FTPS
- SMB

连接远程文件夹后，可以浏览目录、选择文件并导入到漫匣。网络环境不稳定时，建议优先下载到本地后再加入书库。

### 本地传输

传输相关页面用于在设备之间移动文件或接收外部发送的内容。使用时请确认设备在同一网络环境下，并留意系统权限提示。

## 04 漫画阅读与图片阅读器

漫画阅读器面向图片页内容，强调全屏、沉浸和高效翻页。

### 基本操作

- 点击屏幕中部：显示或隐藏工具栏。
- 左右区域点击：按当前阅读方向翻页。
- 音量键：在开启音量键翻页后可用于上一页/下一页。
- 章节列表：从底部或顶部工具栏进入目录，快速切换章节。

### 阅读模式

漫画阅读器会根据内容和设置支持多种阅读方式：

- 单页模式：适合普通漫画。
- 连续滚动：适合条漫或长图阅读。
- 双页或横屏布局：适合平板和大屏设备。
- 图片适配：可在适合宽度、适合高度、原始比例等模式间切换。

### 图片体验

漫匣会尽量优化图片加载、缓存和预加载。阅读大型漫画时，如果遇到短暂空白，通常是正在解压、解码或加载下一页。保持足够存储空间可以提升缓存命中率。

### 在线漫画

通过图源打开的漫画通常会进入统一详情页，再进入阅读器。不同图源的章节结构、图片链接和登录要求可能不同；如果某个图源失效，可以先尝试刷新源、更新扩展仓库或检查网络代理。

## 05 电子书阅读器与 Markdown 支持

电子书阅读器用于阅读 EPUB、PDF、TXT、Markdown 和部分 Kindle 格式。不同格式会使用不同渲染引擎，但它们共享统一的阅读记录、目录、工具栏和设置体验。

### 支持格式

| 格式 | 说明 |
| --- | --- |
| TXT | 适合纯文本和长篇小说 |
| EPUB | 支持目录、排版和 Reader Kit 渲染 |
| PDF | 适合固定版式文档 |
| MD | 使用 Markdown WebView 阅读器渲染 |
| MOBI/AZW/AZW3 | Kindle 类格式，按当前解析能力进入合适阅读链路 |

### 阅读设置

电子书阅读设置会影响 Markdown 手册和普通电子书：

- 字体大小
- 字体、字重
- 行高
- 页面边距
- 文字颜色
- 背景颜色
- 日间、夜间、护眼、羊皮纸等主题
- 翻页模式
- 音量键翻页
- 自动保存进度

Markdown 阅读器会把这些设置应用到正文、标题、列表、表格、代码块和段落排版上。本手册就是一个 Markdown 电子书示例。

### Markdown 目录与跳转

本手册使用 `##` 标题作为电子书章节分割点。阅读器会把这些章节显示在目录面板中。手册目录里的链接使用如下 Markdown 写法：

```markdown
[05 电子书阅读器与 Markdown 支持](https://manxia.local/manual/chapter/5)
```

点击后，漫匣会拦截该链接并跳转到对应章节，不会打开网页。

### Markdown 扩展能力

Markdown 阅读器支持常见排版元素：

- 标题、段落、引用、列表
- 表格
- 代码块和语法高亮
- 图片
- 脚注
- 数学公式
- Mermaid 图表

> 如果某份 Markdown 文件显示异常，优先检查编码是否为 UTF-8、标题层级是否规范、代码块围栏是否闭合。

## 06 小说阅读、书源与听书

小说阅读模块用于本地 TXT、在线书源内容和长文本阅读。

### 小说书架

小说书架可以管理本地小说和从书源加入的作品。你可以查看阅读状态、继续上次阅读、进入详情页或管理章节缓存。

### 小说阅读器

小说阅读器提供更适合长文本的设置：

- 分页、滚动、双页等阅读模式。
- 滑动、仿真、淡入等翻页动画。
- 字体、行高、段落间距、首行缩进。
- 背景颜色或背景图片。
- 页码、进度、时间、电量显示。
- 点击翻页和音量键翻页。

### 听书

听书能力用于把小说或文本内容朗读出来。你可以在支持的页面进入听书设置，配置朗读引擎、语速、音色和缓存策略。听书时会同步阅读位置，方便在阅读和朗读之间切换。

### 书源

书源用于从在线站点搜索、浏览和导入小说。书源通常支持发现分类、搜索、详情、目录、正文抓取等能力。部分站点可能需要登录、代理或等待规则更新。

### 小说规则与净化

小说模块还提供几类偏高级但很实用的规则：

- 替换规则：用于清理广告、错误字符、重复段落或站点注入内容。
- 字典规则：用于统一人名、术语或特殊词汇显示。
- TXT 目录规则：用于从本地长文本中识别章节标题。
- 书源调试：用于检查搜索、详情、目录和正文规则是否正常。

这些规则会影响正文显示和章节识别。调整规则后，建议重新打开目标章节检查效果。

## 07 在线图源、书源与扩展仓库

漫匣的在线内容能力依赖图源、书源和扩展仓库。它们定义了搜索、详情、章节、图片或正文提取等规则。

### 图源

图源主要用于漫画类站点。一个图源通常包含：

- 基本信息：名称、包名、版本、图标。
- 搜索能力：关键词搜索、作者搜索、ID 搜索等。
- 详情能力：标题、封面、简介、标签、章节列表。
- 阅读能力：章节图片、分页、特殊图片处理。
- 网络设置：请求头、速率限制、域名设置、代理策略。

### 书源

书源主要用于小说类站点，通常兼容 Legado 风格规则。书源可以提供搜索、发现分类、详情、目录和正文抓取。

### 扩展仓库

扩展仓库用于集中管理图源和书源。你可以同步仓库、检查更新、启用或禁用来源。遇到来源失效时，优先尝试：

1. 同步扩展仓库。
2. 更新目标来源。
3. 检查是否需要登录。
4. 检查是否需要代理。
5. 查看来源调试或反馈信息。

### 源管理

源管理页面用于查看已安装来源、筛选来源、调整排序、进入设置、登录或调试。高级模式下会显示更多图源相关入口。

### 登录、调试与反馈

部分来源需要登录后才能搜索、查看章节或加载图片。遇到这类来源时，可以进入来源登录页完成站点登录；如果来源规则疑似失效，可以使用来源调试页检查搜索结果、详情解析、章节列表和图片链接。

图源反馈页面用于记录来源问题、复现步骤和必要信息。反馈时尽量写清楚来源名称、作品名称、失败入口和错误现象，便于后续定位。

## 08 Suwayomi 与 Komga 远程书库

漫匣支持连接远程漫画服务，用于访问已经部署在服务器上的漫画库。

### Suwayomi

Suwayomi 是常见的漫画服务端方案。配置完成后，你可以在漫匣中浏览来源、查看漫画详情、阅读章节，并同步服务端相关状态。

常见入口包括：

- Suwayomi 设置
- Suwayomi 浏览
- Suwayomi 来源浏览
- Suwayomi 漫画详情
- Suwayomi 阅读器

### Komga

Komga 更适合自建漫画库、书籍库和阅读列表管理。漫匣支持配置 Komga 实例、浏览库、按系列或书籍查看内容，并进入 Komga 阅读器。

Komga 主标签支持：

- 多实例切换
- 库入口
- 系列、书籍、阅读列表
- 排序和筛选
- 阅读进度筛选
- 封面缓存

### 使用建议

远程服务的体验受服务器性能、网络环境和登录状态影响。如果封面或章节加载缓慢，先检查服务端是否可访问，再检查漫匣中的实例配置和网络代理。

## 09 搜索、详情、订阅与下载

漫匣把搜索、详情、订阅和下载串成一条完整链路。

### 全局搜索

全局搜索用于跨本地书库、图源、书源或远程来源查找内容。使用前请确认对应来源已启用。搜索结果通常会进入统一详情页或来源详情页。

### 详情页

详情页展示作品信息，包括封面、标题、作者、简介、标签、章节列表、阅读状态和操作按钮。对于在线内容，详情页还会负责刷新章节、加入书库、开始阅读或下载。

### 订阅

订阅用于跟踪作品更新。订阅管理页可以查看订阅状态、更新结果和来源信息。对于在线来源，订阅结果依赖来源规则是否可用。

### 下载

下载管理用于查看下载任务、暂停、恢复、失败重试和清理。建议在稳定网络下批量下载，避免来源限速或临时封禁。

### RSS

RSS 相关页面用于订阅和阅读 RSS 内容，适合跟踪站点更新、公告或内容流。你可以管理订阅源、查看订阅详情并进行调试。

RSS 收藏页用于保存之后想回看的条目。调试页可以帮助确认订阅地址、解析结果和更新状态是否正常。

### 在线电子书

在线电子书详情页用于查看来自远程来源的电子书信息、目录和下载状态。支持的入口会根据来源能力显示不同操作，例如加入书库、阅读、下载或刷新详情。

Z-Library 阅读入口适合阅读已经通过对应能力打开的在线电子书。实际可用性受账号状态、网络环境和来源限制影响。

## 10 标注、书签与阅读报告

漫匣会记录你的阅读行为，并提供回看和整理能力。

### 书签

在支持的阅读器中，你可以为当前页面或当前位置添加书签。书签会记录章节、页码、进度等信息，便于之后继续查看。

### 标注

标注中心用于集中查看高亮、笔记或阅读标记。不同格式的标注能力可能不同，固定版式内容和图片内容通常会受到格式限制。

### 阅读报告

阅读报告用于查看阅读统计和趋势，例如最近阅读、总阅读时长、内容类型分布和阅读习惯变化。它适合帮助你了解自己的阅读节奏。

### 追踪与同步状态

追踪设置用于连接外部追踪服务或同步阅读状态。启用后，漫匣可以在支持的内容中记录进度、状态和更新时间。外部服务通常需要登录授权，网络异常时可能延迟同步。

### 阅读进度

漫匣会自动保存阅读进度。不同阅读器保存的信息不同：

| 阅读器 | 进度信息 |
| --- | --- |
| 漫画阅读器 | 当前章节、当前图片页 |
| 电子书阅读器 | 当前章节、页码或 DOM 位置 |
| Markdown 阅读器 | 当前章节、章节内滚动百分比 |
| 小说阅读器 | 当前章节、分页页码或字符位置 |

## 11 设置、主题、备份与存储

设置页用于管理应用级选项。

### 主题设置

主题设置可以调整应用背景、强调色、视觉风格和部分沉浸式效果。阅读器内也有独立阅读主题，用于控制正文背景和文字颜色。

### 全局设置

全局设置用于配置默认阅读模式、下载选项、阅读行为和部分跨页面偏好。不同阅读器仍可能保留自己的细分设置。

常见设置分组包括：

- 页面设置：控制主菜单、详情页、书库点击行为和页面入口显示。
- 阅读设置：控制默认阅读模式、翻页行为、常亮、音量键翻页等。
- 字体设置：控制阅读字体、字号范围和文本显示偏好。
- 交互设置：控制手势、点击区域、震动反馈等操作方式。
- 动画和视觉效果：控制页面过渡、玻璃效果、背景模糊和动态效果。
- 网络设置：控制代理、请求行为和部分网络访问策略。
- 来源功能设置：控制图源、书源、在线功能和高级来源入口。

### 备份与恢复

备份功能用于保存书库、设置、来源、订阅和部分数据库记录。迁移设备或重装应用前，建议先创建备份并确认备份文件可访问。

备份选项通常会区分书库数据、设置与历史、媒体文件和高级选项。恢复时请先确认目标设备上的本地文件路径是否仍然有效。

### 存储管理

存储管理用于查看缓存和数据占用。你可以清理封面缓存、图片缓存、章节缓存或临时文件。清理前请确认不会删除仍需要离线阅读的内容。

### 数据管理与传输

数据管理页集中处理导入、导出、同步、网络文件夹和本地传输相关入口。传输页适合在局域网内接收或发送内容；Download 同步页适合把系统下载目录中的文件加入书库。

### 通知、重复检测与快捷操作

通知设置用于控制订阅更新、下载任务或阅读相关提醒。重复检测可以帮助找出疑似重复导入的内容。快捷操作设置用于调整常用入口和操作习惯，让高频功能更容易到达。

### 错误管理、日志与高级设置

错误管理和日志页面用于查看异常记录、运行状态和调试信息。普通使用中不需要频繁进入，但在反馈问题时，这些信息可以帮助定位具体模块。

高级设置会暴露更多实验性或开发向选项。不了解影响时，建议保持默认状态。

### 网络与代理

部分来源可能需要代理、登录或额外请求头。代理设置和来源设置可以帮助解决站点访问限制，但也应遵守目标站点规则。

### 关于应用

关于页面包含版本信息、开源许可、隐私政策、用户协议和支持项目等入口。

## 12 Markdown 书籍写作规范

漫匣现在可以把 Markdown 当作电子书阅读。为了获得最稳定的体验，建议按以下规范写作。

### 基础结构

推荐结构：

```markdown
# 书名

简短介绍。

## 第一章 标题

正文内容。

### 小节标题

更多内容。
```

在内置使用手册中，`##` 会被识别为电子书章节。`###` 及更深层级适合作为章节内小节。

### 推荐语法

- 使用 `#`、`##`、`###` 表示标题层级。
- 使用空行分隔段落。
- 使用 `-` 或 `1.` 编写列表。
- 使用标准表格语法。
- 代码块使用三个反引号围栏。
- 图片使用 `![描述](路径或链接)`。
- 脚注使用 `[^name]` 与 `[^name]: 内容`。

### 表格示例

| 目标 | 推荐写法 |
| --- | --- |
| 分章 | `## 章节标题` |
| 小节 | `### 小节标题` |
| 强调 | `**重点内容**` |
| 代码 | `` `inlineCode` `` |

### 跳转链接

手册内跨章节跳转使用下面的合法 Markdown 链接：

```markdown
[返回目录](https://manxia.local/manual/chapter/0)
```

普通 Markdown 文件也可以使用 `#标题锚点` 进行同页跳转，但跨章节跳转需要阅读器支持。本手册使用漫匣内置链接处理来完成跨章节跳转。

## 13 常见问题与排查建议

### 手册目录看不到多个章节

请确认当前内置手册版本已经更新。新版手册会按 `##` 标题拆成多个电子书章节。如果仍只有一章，可以尝试从书库中删除旧手册后重新启动应用，或等待欢迎引导重新写入内置手册。

### Markdown 内容空白

优先检查：

1. 文件是否为 UTF-8 编码。
2. Markdown 内容是否真实写入 rawfile。
3. 代码块、表格或数学公式是否存在未闭合语法。
4. 阅读器是否正在使用 Markdown 引擎，而不是普通文本阅读器。

### 在线来源搜索失败

可能原因包括来源规则失效、站点结构变化、网络受限、需要登录、需要代理或触发站点风控。建议先同步扩展仓库，再检查来源设置。

### 图片加载慢

可能原因包括图片过大、网络慢、远程服务响应慢、缓存不足或来源限速。可以尝试降低并发、清理缓存、切换网络或稍后重试。

### 阅读进度没有恢复

请确认自动保存进度已开启，并正常退出阅读器。对于 Markdown 电子书，漫匣会保存当前章节和章节内滚动百分比；对于普通 EPUB，可能保存 Reader Kit 的 DOM 位置。

### 备份前要注意什么

备份前建议：

- 保持电量充足。
- 确认备份位置可写。
- 不要在备份过程中强制关闭应用。
- 迁移设备后先恢复设置和来源，再检查本地文件路径是否仍然有效。

感谢你阅读本手册。希望漫匣能成为一个安静、可靠、顺手的阅读空间。
