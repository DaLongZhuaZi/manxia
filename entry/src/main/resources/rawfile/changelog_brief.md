# 更新日志

## v0.1.4 (105202300)

### 阅读与搜索
- 修复统一详情页竖屏阅读按钮显示与横屏阅读操作定位；搜索历史支持长按删除单条记录，并可通过确认对话框一键清空，删除结果同步保存。

### 启动与书源兼容性
- 小说模块启动先完成数据库和基础书源索引，Legado V2 兼容编译与 IMAGE 虚拟图源同步改为后台逐源恢复；搜索、详情、目录、正文和发现入口会按需等待目标书源就绪。
- 统一内容跟踪服务移出启动关键路径，并增加并发初始化去重，减少冷启动阻塞。

### 远程书库与欢迎引导
- Suwayomi 与 Komga 默认不在主页面底栏显示，可在欢迎引导中分别开启入口并进入服务配置；引导完成增加上滑淡出过渡。

### 传书与电子书
- 修复已配对 Web 客户端上传时仍被要求重复提供令牌或配对码的问题；电子书保存会保留阅读设置和解压目录，删除时清理受管理文件及统一批注，并修复 EPUB 划线与 MOBI 转换残留问题。

### 模块化与资源治理
- 完成核心、主题、网络、小说、阅读器与功能 UI 的 HAR 职责拆分，补齐显式依赖并清理模块内自引用、冗余依赖和孤儿文件。
- 新增共享 UI 资源 HAR 与 `ResourceCatalog`，统一媒体/颜色/字符串解析；迁移公共资源和编辑器 rawfile，并兼容旧版电子书封面资源键。

### 稳定性与测试
- Base64、JWT、Legado、传书和偏好设置等链路迁移到异步 API，补充认证、分页、WebView、数据库迁移等明确类型；新增依赖、资源归属、ArkTS 静态门禁及关键链路回归检查。
