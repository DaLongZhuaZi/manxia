# 更新日志

## v0.1.2 (104902302)

### EPUB 阅读
- EPUB 会从 OPF 自动刷新 spine 章节、资源路径、媒体类型和版式标记，旧导入数据也能在打开时修正。
- 支持从 container.xml、常见 OPF 路径和嵌套目录定位 package document，并在解压缓存缺资源时尝试重新解压。
- 新增封面页、图片页和出版物固定版式识别，封面会按整页居中显示，减少裁切、拉伸和空白页。
- 出版物版式、封面页和图片页统一按单页处理，分页状态更稳定。
- 跨章节切换新增上一帧快照遮罩，翻页动画不再压暗页面，减少 WebView 重载时的闪白。

### 窗口与主页
- WindowManager 新增主窗口尺寸、窗口状态和自由窗口模式监听，并通过 AppStorage 发布布局快照。
- 窗口变化会同步刷新系统栏高度缓存，改善横竖屏、自由窗口和最大化切换后的安全区表现。
- 主页底栏会跟随窗口布局变化重新计算视口、位移和响应式参数，减少底栏错位。

### 兼容性
- 欢迎引导页会在模拟器环境自动关闭不可用的系统 ReaderKit 能力，并同步设置与提示结果。
- 文件列表读取前会先确认目标是目录，降低坏包、旧缓存和异常路径造成的解析失败。
- EPUB 解析日志补充 OPF、spine、封面和缺失资源信息，问题定位更直接。

### 图源与依赖
- extensions-source 子仓库同步到最新图源提交区间，包含多站点新增、域名更新、搜索、分页、章节和解密修复。
- 拷贝漫画扩展说明补充 Ko-fi 与爱发电支持入口。
- AVIF 本地构建依赖目录保留 aom/zlib 构建缓存和 zlib 状态变化，便于后续原生构建排查。
