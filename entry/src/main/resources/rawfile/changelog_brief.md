# 更新日志

## v0.1.3 (105002301)

### 漫画单页重试
- 漫画图片失败后会先自动重试；手动重试会先复用缓存，再升级为强制刷新，避免单张坏图阻塞整章阅读。
- 单页、双页、预览和 Webtoon 模式统一显示失败状态与重试入口，并通过加载代次隔离迟到回调，减少旧结果覆盖新页面。

### Komga 与 Suwayomi
- Komga 阅读器支持单图自动/手动重试、渲染失败恢复和封面/页面缓存失效，重新加载时可绕过损坏缓存。
- Suwayomi 阅读器补齐下载、AVIF 解码和图片渲染失败重试，切换章节后会丢弃旧章节的迟到结果。

### 图片缓存与测试
- 强制刷新会绕过内存缓存、磁盘缓存和失败冷却，并使用独立加载任务；在线下载内容可回退网络地址重新获取。
- 修正 Webtoon 页面索引解析，新增重试状态、强制刷新请求和页面隔离相关单元测试。
