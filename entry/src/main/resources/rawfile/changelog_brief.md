# 更新日志

## v0.1.3 (105002300)

### 漫匣支持者计划
- 新增支持者计划页面、协议说明和专属功能展示，支持查看权益、跳转相关设置并在本机激活/取消激活。
- 支持者可保存赞赏码并跳转微信，赞赏入口补充“推荐”提示；支持者状态仅用于本机功能展示。

### 支持者名单与远程更新
- 支持者名单改为独立数据管理器，优先读取本地 rawfile 和缓存，并按间隔静默刷新远程数据。
- 远程请求支持主站与代理路由切换、失败冷却和缓存回退，更新成功后自动刷新支持者页面。

### 设置与阅读器
- 设置搜索新增阅读器多开、后台隐私遮罩、全局自定义背景和 EPUB WebView 渲染定位，并增加命中高亮。
- 漫画与小说阅读器稳定记录工具栏状态栏高度，减少安全区变化导致的工具栏跳动、点击区域错位和菜单位置异常。
