# 更新日志

## v0.1.2 (104902307)

### 本地漫画导入
- 批量导入会为本地漫画和章节生成稳定身份，减少重复导入、空标题误合并和章节错配。
- 支持更准确解析 ComicInfo.xml、平铺散图目录、多章节压缩包与嵌套压缩包，保留章节路径、页数、状态、NSFW 和发布时间。

### 文件与数据安全
- 压缩包解压改为更安全的 URI 流式复制、临时文件清理、符号链接跳过、大小/数量限制和失败回滚。
- 数据库新增章节创建结果、重复插入忽略、章节数刷新、不完整本地导入清理，以及删除漫画时的目录/封面引用保护。

### 阅读器与同步
- 阅读器返回、独立窗口退出和书本转场增加生命周期校验、超时兜底和截图资源释放，减少黑屏、卡住和迟到回调覆盖状态。
- 数据管理、下载同步和 README 围绕本地漫画导入、清理、格式支持与 API 23 信息同步更新。
