# 更新日志

## v0.1.2 (104902300)

### 在线漫画缓存
- Download 目录授权状态现在会同步给缓存管理流程，已连接目录后不再反复提示授权。
- 缓存章节对话框会在下载完成后自动刷新，已缓存章节会自动跳过并置灰。
- 在线漫画下载会优先复用数据库页表和预取页表，必要时再回退图源拉取。
- 旧归档缺少页表时也能按 CBZ 存在状态识别为已缓存章节。

### 已下载在线漫画阅读
- 已缓存在线漫画支持本地首图优先显示，首屏不再被隐藏 WebView 预热阻塞。
- 首图显示后仍会自动完成 WebView/图源完整预热，未下载章节和网络兜底能力不丢失。
- 阅读监控新增预热状态、归档路径、解压目录、复用状态和页数统计。
- CBZ 解压目录可复用，减少重复解压等待。

### 章节排序
- 统一详情页新增章节排序编辑，可保存自定义顺序或恢复来源顺序。
- 自定义章节顺序会持久化，并在重新进入详情页或刷新内容后继续生效。
- 排序后会重映射阅读进度，并迁移小说正文缓存、朗读音频缓存和远程听书缓存。

### 全局搜索
- 完整搜索结果支持运行期缓存，重复搜索同一条件时更快。
- 搜索结果会按标题、作者和简介匹配度重排，失败或无结果来源会在结束后自动隐藏。
- 搜索历史改为持久化保存，并支持去重和自动整理。
- 展开结果使用固定网格布局，浏览时更稳定。

### 图源与 WebView
- API 分页请求不再直接修改原始图源配置，减少页码参数残留问题。
- 图源 action 克隆补齐请求头、请求体、提取、分页、校验和条件分支配置。
- 页面列表请求增加串行队列，降低并发拉取时的上下文互相覆盖风险。

### 修复优化
- 降低独立阅读器关闭阶段的窗口生命周期误报，不再把正常销毁竞争记为错误。
- 系统栏高度刷新遇到失效窗口时会跳过，避免覆盖已有安全区高度。
- 内容追踪卡片支持更清晰的展开状态，并修正自动创建规则后的状态同步。
- 本地漫画章节查询统一按章节序号排序。
