# 更新日志

## v0.1.4 (105002302)

### 反馈中心
- 应用内新增反馈中心，支持按图源/书源/软件/界面/建议/其他分类提交，可附带图片、视频与压缩包，采用分块上传并自动重试，弱网也能送达。

### Legado V2 书源引擎
- 新增 Legado 书源编译与执行引擎：编译时保留源文档并逐条诊断，统一调度搜索、详情、目录、正文与发现等工作流，并提供真实书源资格跑分与 ArkWeb 合规校验。

### 分布式接续
- 修复跨端接续冷启动时「数据库未初始化」导致落地页解析失败的问题；优化遥控器自动拉起时序，解决连续流转后源端停留桌面、遥控器无法唤起的问题。

### 网络与解析
- 新增网络传输失败分类与熔断，区分 DNS/TLS/超时/HTTP/网络错误；内置 JSoup HTML 实体解析库，书源规则里的 HTML 实体不再依赖外部环境即可正确解码。

### 测试
- 新增 Legado 兼容性、执行取消、网络传输治理等一致性测试与本地单元测试。

## v0.1.3 (105002301)

### 漫画单页重试
- 漫画图片失败后会先自动重试；手动重试会先复用缓存，再升级为强制刷新，避免单张坏图阻塞整章阅读。
- 单页、双页、预览和 Webtoon 模式统一显示失败状态与重试入口，并通过加载代次隔离迟到回调，减少旧结果覆盖新页面。

### Komga 与 Suwayomi
- Komga 阅读器支持单图自动/手动重试、渲染失败恢复和封面/页面缓存失效，重新加载时可绕过损坏缓存。
- Suwayomi 阅读器补齐下载、AVIF 解码和图片渲染失败重试，切换章节后会丢弃旧章节的迟到结果。

### 图片缓存与测试
- 强制刷新会绕过内存缓存、磁盘缓存和失败冷却，并使用独立加载任务；在线下载内容可回退网络地址重新获取。
- 修正 Webtoon 页面索引解析，新增重试状态、强制刷新请求和页面隔离相关单元测试。
