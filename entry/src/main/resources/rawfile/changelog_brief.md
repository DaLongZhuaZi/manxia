# 更新日志

## v0.1.2 (104902304)

### 阅读器与方向锁定
- 小说、本地/在线电子书、Markdown 与漫画阅读器的方向锁定入口和操作逻辑对齐，阅读设置页新增全局开关。
- 打开目录、设置、书籍信息等浮层时，阅读器顶部信息栏更稳定；电子书/文本阅读设置会随备份完整导出与恢复。

### Markdown 阅读
- Markdown 手册改为专用渲染链路，支持标题、列表、代码块、链接和阅读进度美化显示，进入后不再先显示空白页。
- 长 Markdown 页面支持章节、锚点和小分点精确跳转，普通目录跳转会回到页面开头。

### 图源诊断与编辑
- 新增图源诊断中心，可记录 workflow、action、选择器、脚本、当前 URL 和 WebView 事件，把失败定位到具体步骤。
- 新增交互式图源编辑器和悬浮检查器，支持 ArkWeb 点选 DOM、生成规则、预览结果，并保存本地派生副本、覆盖或导出图源。

### 图源详情与封面
- 图源详情页改为统一加载状态机，有缓存先展示并后台刷新，失败与空结果分开显示，链接直达作品后也会补齐列表上下文。
- 封面增加本地/网络/失败状态、首屏预热和多入口本地解码兜底，恢复按图片比例智能显示。

### 其他
- 图源页面入口、小窗拖动、开发者应用列表、测试邀请链接和版本号同步更新。
