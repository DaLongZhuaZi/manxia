# 更新日志

## v0.1.4 (105402300)

### PDF 原生阅读与导入
- 新增 PDF 能力探针页并接入测试管理中心，加载、大纲、文本抽取、全文检索、加密、批注、缩放适配、大文件与自建索引等 18 项在真机全部通过。
- 导入对话框新增「原生阅读（推荐）/ 图片化（兼容）」；电子书选择器支持 `.pdf`；原生模式改为单弹窗导入，用确认的元数据覆盖文件名时间戳标题，并修复封面提取失败与随机标题问题。
- PDF 解析改用 `getMetadata()` 回填元数据；阅读设置统一复用电子书设置面板并按 API 逐项落地，面板对固定版式的不可用项显式说明。
- 底栏新增「搜索」并改为展示结构化大纲；进度条可点击跳页；搜索不再自动跳转，仅在点击上一处/下一处时跳转；清理重复的更多菜单入口与自造显示面板。

### 全文检索与文本索引
- 中文检索优先使用引擎视图级检索，未命中时回退到自建逐页文本索引定位页码；扫描件自动识别并跳过索引。

### 阅读器 UI 与交互
- 工具栏与顶栏按钮支持「图标 + 文字」提示，可在阅读设置中开关，覆盖全部阅读器，并修复按钮回调失效问题。
- 漫画首次阅读按页面尺寸自动切换条漫/宽图横屏模式；统一交互提示触发时机。
- 方向锁定统一为窗口级请求栈，全局锁定后阅读器不再随陀螺仪旋转，并在设置中说明规则。

### 电子书与详情页
- 电子书详情页新增「分享」原文件入口，基于导入后的工作副本分享，按扩展名映射分享类型。

### 内置字体与开源许可
- 得意黑（Smiley Sans）转为内置字体，无需导入即可在字体管理与各阅读器中使用，管理页显示「内置」标记且不可删除。
- 开源许可页新增内置字体（SIL OFL 1.1）与 PDFium（BSD-3-Clause）条目及许可全文，并版本化留存到 `docs/licenses`。

### 工程治理与包体优化
- 归档 782 个历史备份文件（约 119 MB）到根目录归档目录并生成清单。
- PDF 相关组件与测试页颜色改用系统颜色资源、列表补齐显式宽高、测试页补充返回路径。
- 完成 PDFium 引入调研，输出包含构建、集成、分阶段计划、体积预算、许可与风险的方案文档。
### 跨端接续
- 新增「仅阅读缓存」「导入书库」两种接续模式，配套传输清单校验、缓存历史与设置页；修复 TXT、电子书、漫画的打包恢复与进度处理。
- 修复接续封面长期占位、遥控器返回白屏；漫画阅读器新增适宽、适高、原始比例布局。

### 权限合规
- 「设备发现和连接」改为可选：未授权不影响其它功能，不自动退出、不反复弹窗，接续入口给出明确说明，仅在用户主动触发时申请。

### 远端图源与阅读修复
- 漫画 AVIF 接入原生解码，修复部分图源整章空白。
- Komga：协议自适应并记住可用协议；取页分可见/预加载双通道并限制积压；失败 30 秒抑制、消除重复下载；错误输出错误码；系列封面不再裁切。
- 阅读器占位区显示排队/取页/解码/失败阶段与已等待时长。

### 字体与设置
- 漫画阅读器设置面板与查看器接入全局字体。
- Suwayomi 详情页移除概览、修复按钮溢出、新增章节排序、简介标签可展开收起。
