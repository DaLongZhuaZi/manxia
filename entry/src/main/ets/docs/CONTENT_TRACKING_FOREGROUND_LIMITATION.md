# 内容更新提醒当前行为说明

更新时间：2026-04-21

## 当前现状

当前版本的内容更新提醒，规则、筛选、提醒和自动下载都已经接通，但自动检查还不是后台定时任务。

现在的真实行为是：

1. 手动点击“立即检查”时，会立刻在前台执行一次。
2. 自动检查只会在 APP 回到前台时，补查已经到期的提醒规则。
3. APP 退到后台后，不会按分钟、小时、天、周准时自动执行检查。

## 当前触发方式

- 规则是否到期，仍然按 `checkIntervalMin` 判断。
- 自动补查入口目前挂在应用进入前台的回调上。
- 规则到期后，需要等用户再次回到 APP，才会触发自动补查。

## 对用户文案的统一要求

涉及内容更新提醒的页面、组件、弹窗和提示，统一使用下面这类说法：

- 自动检查目前只会在 APP 回到前台时补查，后台不会定时执行。
- 当前版本仅支持前台补查，不支持后台准时检查。

不要再使用会让用户误以为“APP 在后台也会按时自动检查”的文案。

## 后续规划

如果后面继续推进后台能力，优先考虑：

1. 保留现有“手动立即检查 + 回到前台补查”。
2. 评估 `WorkSchedulerExtensionAbility` 做“尽力而为”的后台调度。
3. 不承诺分钟级、绝对准点的后台轮询。
4. 如果未来需要更及时的更新提醒，再考虑服务端检查和推送。
