# 数据管理功能使用说明

## 概述

数据管理功能是漫匣应用的核心功能之一，提供了完整的漫画文件导入、解压缩、XML解析和数据库导入能力。用户可以通过此功能将本地的CBZ/ZIP格式漫画文件导入到应用中进行管理和阅读。

## 功能特性

### 🎯 核心功能
- **文件导入**: 支持选择和导入CBZ/ZIP格式的漫画压缩文件
- **自动解压**: 智能解压缩漫画文件，提取图片和元数据
- **XML解析**: 自动解析ComicInfo.xml文件，获取漫画详细信息
- **数据库集成**: 将解析的漫画信息保存到本地数据库
- **批量处理**: 支持同时导入多个漫画文件

### 🧪 测试功能
- **基础测试**: 验证XML解析器、解压缩工具和数据库集成功能
- **完整流程测试**: 模拟完整的导入流程，验证各组件协作
- **UI功能测试**: 测试用户界面组件和交互功能

### 🎨 界面特性
- **沉浸式设计**: 采用完全沉浸式显示，提供现代化的用户体验
- **主题适配**: 支持浅色/深色主题自动切换
- **响应式布局**: 适配不同屏幕尺寸和设备类型
- **实时反馈**: 提供详细的进度显示和状态反馈

## 使用指南

### 1. 访问数据管理页面

从主菜单选择"数据管理"选项，即可进入数据管理页面。

### 2. 功能测试

在开始导入文件之前，建议先运行功能测试以确保系统正常工作：

#### 基础测试
- 点击"运行基础测试"按钮
- 系统将自动测试XML解析器、解压缩工具和数据库集成功能
- 查看测试结果，确保所有测试项目都通过

#### 完整流程测试
- 点击"测试完整流程"按钮
- 系统将模拟完整的导入流程
- 验证数据转换和数据库导入功能

#### UI功能测试
- 点击"测试UI功能"按钮
- 系统将测试页面组件渲染、按钮交互、状态管理等UI功能
- 查看详细的测试报告

### 3. 文件导入

#### 选择文件
1. 点击"选择文件"按钮
2. 在文件选择器中选择CBZ或ZIP格式的漫画文件
3. 支持多选，可以同时选择多个文件

#### 开始导入
1. 选择文件后，点击"开始导入"按钮
2. 系统将自动执行以下步骤：
   - 验证文件格式
   - 解压缩文件
   - 查找并解析ComicInfo.xml
   - 扫描图片文件
   - 导入数据库
   - 清理临时文件

#### 查看进度
- 导入过程中会显示实时进度
- 包括当前处理的文件名和完成百分比
- 可以查看详细的处理日志

### 4. 结果查看

导入完成后，可以查看：
- 成功导入的文件数量
- 失败的文件及错误原因
- 详细的处理日志

## 支持的文件格式

### 压缩文件格式
- **CBZ**: Comic Book ZIP，标准漫画压缩格式
- **ZIP**: 通用ZIP压缩格式

### 图片格式
- **JPEG/JPG**: 最常用的图片格式
- **PNG**: 支持透明背景的图片格式
- **WEBP**: 现代高效的图片格式
- **BMP**: 位图格式

### 元数据格式
- **ComicInfo.xml**: 标准漫画元数据格式，包含标题、作者、描述等信息

## ComicInfo.xml 支持的字段

数据管理功能支持解析以下ComicInfo.xml字段：

### 基本信息
- `Title`: 漫画标题
- `Series`: 系列名称
- `Number`: 章节号
- `Summary`: 内容摘要
- `Writer`: 作者
- `Genre`: 类型/标签

### 发布信息
- `Web`: 官方网站
- `PublishingStatus`: 发布状态（Ongoing/Completed等）
- `Source`: 来源信息

### 扩展字段
- `Year`: 发布年份
- `Month`: 发布月份
- `Day`: 发布日期
- `PageCount`: 页数

## 技术架构

### 核心组件

#### ComicInfoParser
- **功能**: XML解析和数据映射
- **位置**: `/Utils/ComicInfoParser.ets`
- **特性**: 
  - 使用HarmonyOS原生XML解析API
  - 支持字段验证和默认值处理
  - 提供类型安全的数据转换

#### CompressionUtils
- **功能**: 文件解压缩和管理
- **位置**: `/Utils/CompressionUtils.ets`
- **特性**:
  - 基于@kit.BasicServicesKit的zlib实现
  - 支持文件验证和安全检查
  - 提供详细的错误处理

#### DataManager集成
- **功能**: 数据库操作和数据持久化
- **接口**: `ComicInfoInput`, `ChapterInfoInput`, `PageInfoInput`
- **特性**:
  - 类型安全的数据接口
  - 支持事务处理
  - 提供数据验证

### 数据流程

```
文件选择 → 格式验证 → 解压缩 → XML解析 → 图片扫描 → 数据转换 → 数据库导入 → 清理临时文件
```

### 错误处理

系统提供多层次的错误处理：
1. **文件级错误**: 文件格式不支持、文件损坏等
2. **解析错误**: XML格式错误、字段缺失等
3. **数据库错误**: 插入失败、约束冲突等
4. **系统错误**: 内存不足、权限问题等

## 故障排除

### 常见问题

#### 文件导入失败
**问题**: 选择文件后导入失败
**解决方案**:
1. 检查文件格式是否为CBZ或ZIP
2. 确认文件没有损坏
3. 检查设备存储空间是否充足
4. 查看错误日志获取详细信息

#### XML解析失败
**问题**: ComicInfo.xml解析失败
**解决方案**:
1. 检查XML文件格式是否正确
2. 确认字符编码为UTF-8
3. 验证XML结构是否符合标准
4. 系统会使用默认值继续处理

#### 数据库导入失败
**问题**: 数据保存到数据库失败
**解决方案**:
1. 检查数据库连接状态
2. 确认数据格式符合要求
3. 检查是否存在重复数据
4. 重启应用重新尝试

## 最佳实践

### 文件准备
1. 确保漫画文件为标准CBZ格式
2. 包含完整的ComicInfo.xml元数据
3. 图片文件命名规范（如：001.jpg, 002.jpg）
4. 文件大小控制在合理范围内

### 批量导入
1. 建议单次导入文件数量不超过50个
2. 大文件建议分批处理
3. 导入前先运行测试确保系统正常
4. 定期清理临时文件释放存储空间

### 数据管理
1. 定期备份数据库
2. 避免重复导入相同文件
3. 及时清理无效数据
4. 监控存储空间使用情况
