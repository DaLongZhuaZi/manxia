# 系统分享导入功能测试指南

## 测试环境准备

### 必需条件
1. ✅ HarmonyOS NEXT 设备或模拟器
2. ✅ 应用已安装并完成初始配置
3. ✅ 准备测试文件：至少2-3个ZIP或CBZ格式的漫画文件

### 推荐测试文件
- `test_comic_1.zip` (小文件，约5MB)
- `test_comic_2.cbz` (中等文件，约20MB)
- `test_comic_batch.zip` (多文件测试)

## 测试用例

### 测试用例 1：单文件分享导入

**目的**: 验证单个文件的基本分享功能

**步骤**:
1. 打开系统文件管理器
2. 找到测试漫画文件 `test_comic_1.zip`
3. 长按文件，选择"分享"
4. 在分享菜单中找到"漫匣"应用
5. 点击"漫匣"图标

**预期结果**:
- ✅ 应用自动启动（或从后台切换到前台）
- ✅ 自动导航到"数据管理"页面
- ✅ 文件自动添加到选中列表
- ✅ 显示："已接收 1 个文件（系统分享）"
- ✅ 1秒后自动开始导入流程
- ✅ 导入成功后显示成功提示

**日志检查点**:
```

[ShareExtAbility] ✅ 有效的漫画文件: file://...
[EntryAbility] 📤 通过系统分享接收文件: 1 个
```

## 常见问题排查

### Q1: 分享菜单中没有"漫匣"应用

**可能原因**:
1. ShareExtAbility 未正确注册
2. module.json5 配置错误
3. 应用未安装或已卸载

**检查**:
- 确认 `module.json5` 中 `extensionAbilities` 配置正确
- 检查 `skills` 中的 `actions` 和 `uris` 配置
- 重新安装应用

---

### Q2: 分享后应用无响应

**可能原因**:
1. EntryAbility 未接收到参数
2. AppStorage 数据未正确设置
3. MainMenuPage 未检测到分享标记

**检查**:
- 查看日志，确认 `EntryAbility.handleShareImport` 被调用
- 验证 `pendingShareFiles` 是否存在于 AppStorage
- 确认 `MainMenuPage.checkPendingShareImport` 执行

---

### Q3: 文件导入失败

**可能原因**:
1. 文件URI无效或权限不足
2. 文件格式不支持
3. 磁盘空间不足
4. 文件已存在（重复导入）

**检查**:
- 查看导入错误日志
- 验证文件URI格式
- 检查存储空间
- 查看数据库是否已有相同文件
