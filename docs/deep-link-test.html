📖 URL 格式说明

基本格式：

manxia://search/{图源名称}?type={搜索类型}&query={搜索内容}

支持的图源名称：

  • pixiv - Pixiv
  • jinmantiantang 或 jm - 禁漫天堂
  • picacomic 或 pica 或 bika - 哔咔漫画

支持的搜索类型：

  • id - 作品ID搜索
  • user 或 author - 用户/作者搜索（仅Pixiv）
