### 1. 数据库架构更新

#### 新增字段（comic_source表）
- `preloadCurrentChapter` (INTEGER): 是否预加载当前章节（0/1），默认1
- `preloadCurrentPages` (INTEGER): 当前章节预加载页数，默认3
  - 0 = 不预加载
  - -1 = 预加载全部
  - 正数 = 预加载指定页数
- `preloadNextChapter` (INTEGER): 是否预加载下一章节（0/1），默认1
- `preloadNextPages` (INTEGER): 下一章节预加载页数，默认-1（全部）
  - 0 = 不预加载
  - -1 = 预加载全部
  - 正数 = 预加载指定页数

### 3. 预加载逻辑实现

#### 新增字段
```typescript
private sourcePreloadSettings: SourcePreloadSettings = {
  preloadCurrentChapter: true,
  preloadCurrentPages: 3,
  preloadNextChapter: true,
  preloadNextPages: -1
};
```

#### 新增方法

**1. loadSourcePreloadSettings(sourceId: number)**
- 从数据库加载图源的预加载设置
- 在 MangaSourceEngine 初始化后自动调用
- 使用默认值作为回退

**2. preloadNextChapterAfterCurrentLoaded()**
- 在当前章节页面信息加载完成后立即调用
- 检查是否启用下一章节预加载
- 立即预加载下一章节（与阅读进度无关）
- 触发时机：第1835行（保存页面信息后）

**3. preloadChapterPages(chapter, maxPages)**
- 支持 `maxPages` 参数控制预加载页数
- `maxPages = -1`: 预加载全部页面
- `maxPages = 0`: 不预加载
- `maxPages > 0`: 预加载指定数量的页面
- 所有获取到的页面信息都会保存到数据库

**4. preloadNextChapterIfNeeded(currentPageIndex)** - 已废弃
- 保留空实现以兼容现有调用
- 已被 `preloadNextChapterAfterCurrentLoaded` 替代

### 4. 工作流程

```
用户打开漫画阅读器
    ↓
初始化 MangaSourceEngine
    ↓
加载图源预加载设置 (loadSourcePreloadSettings)
    ↓
加载当前章节页面信息（通过 getPageList）
    ↓
保存页面信息到 online_page 表
    ↓
立即检查并预加载下一章节 (preloadNextChapterAfterCurrentLoaded)
    ↓
如果启用且有下一章节：
  - 调用 preloadChapterPages(nextChapter, preloadNextPages)
  - 获取下一章节的页面列表
  - 根据 preloadNextPages 设置决定预加载多少页
  - 保存所有页面信息到数据库
    ↓
用户切换到下一章节时，直接使用已保存的页面信息
```

#### 实现逻辑
```typescript
// 在页面变化时触发
private preloadCurrentChapterPages(currentPageIndex: number): void {
  if (!this.sourcePreloadSettings.preloadCurrentChapter) {
    return;
  }
  
  const chapter = this.readerState.currentChapter;
  const maxPages = this.sourcePreloadSettings.preloadCurrentPages;
  
  // 计算需要预加载的页面范围
  let startIndex = currentPageIndex + 1;
  let endIndex = maxPages === -1 
    ? chapter.pages.length 
    : Math.min(startIndex + maxPages, chapter.pages.length);
  
  // 预加载这些页面的图片（调用 ImageCacheManager）
  for (let i = startIndex; i < endIndex; i++) {
    const page = chapter.pages[i];
    if (page.sourceType === ImageSourceType.NETWORK) {
      this.preloadPageImage(page);
    }
  }
}
```
