## 🧪 测试准备

### 1. 数据库迁移测试

启动应用后，检查日志：

```
✅ 应该看到：
[DatabaseManager] 开始检查并确保comic_source表的预加载设置列存在
[DatabaseManager] 已为comic_source添加preloadCurrentChapter列
[DatabaseManager] 已为comic_source添加preloadCurrentPages列
[DatabaseManager] 已为comic_source添加preloadNextChapter列
[DatabaseManager] 已为comic_source添加preloadNextPages列
```

### 2. 数据库验证

使用数据库工具查询：

```sql
-- 查看表结构
PRAGMA table_info('comic_source');

-- 应该看到新增的4个字段：
-- preloadCurrentChapter | INTEGER | 0 | 1
-- preloadCurrentPages   | INTEGER | 0 | 3
-- preloadNextChapter    | INTEGER | 0 | 1
-- preloadNextPages      | INTEGER | 0 | -1

-- 查看所有图源的预加载设置
SELECT 
  id, 
  name, 
  preloadCurrentChapter, 
  preloadCurrentPages, 
  preloadNextChapter, 
  preloadNextPages 
FROM comic_source;
```

## 🐛 常见问题排查

### 问题1：预加载设置未加载

**症状：**
```
[MangaReaderPage] ⚠️ 未找到图源ID=5的预加载设置，使用默认值
```

**排查：**
1. 检查 `comic_source` 表是否有该图源
2. 检查预加载字段是否存在
3. 检查 sourceId 是否正确

### 问题2：预加载未触发

**症状：**
- 日志中没有预加载相关信息

**排查：**
1. 检查 `preloadNextChapter` 是否为1
2. 检查是否是最后一章
3. 检查 `currentSourceId` 是否大于0
4. 检查 `mangaEngine` 是否已初始化

### 问题3：预加载失败

**症状：**
```
[MangaReaderPage] 预加载下一章节失败: xxx
```

**排查：**
1. 检查网络连接
2. 检查图源是否正常
3. 检查章节ID是否正确
4. 查看完整错误堆栈

### 问题4：页面信息未保存

**症状：**
- 切换章节时仍然需要网络请求

**排查：**
```sql
-- 检查 online_page 表
SELECT * FROM online_page WHERE chapterId = '章节ID';

-- 如果为空，检查保存逻辑
```

## 🔧 手动测试命令

### 查看预加载设置
```sql
SELECT * FROM comic_source WHERE id = 5;
```

### 修改预加载设置
```sql
-- 关闭下一章节预加载
UPDATE comic_source SET preloadNextChapter = 0 WHERE id = 5;

-- 预加载5页
UPDATE comic_source SET preloadNextPages = 5 WHERE id = 5;

-- 预加载全部
UPDATE comic_source SET preloadNextPages = -1 WHERE id = 5;
```

### 查看预加载的页面
```sql
SELECT 
  c.title as chapterTitle,
  COUNT(p.id) as pageCount
FROM online_chapter c
LEFT JOIN online_page p ON c.id = p.chapterId
WHERE c.comicId = '漫画ID'
GROUP BY c.id
ORDER BY c.chapterIndex;
```

### 清除预加载数据
```sql
-- 清除特定章节的页面信息
DELETE FROM online_page WHERE chapterId = '章节ID';

-- 清除所有页面信息
DELETE FROM online_page;
```
