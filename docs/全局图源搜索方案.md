# 全局图源搜索方案

## 功能需求

支持在主页面使用特定前缀格式进行跨图源搜索，格式为：
```
图源名称//搜索类型//搜索内容
```

## 示例

### Pixiv
- `pixiv//id//139692726` - 搜索作品ID
- `pixiv//user//67890` - 搜索用户ID

### 禁漫天堂
- `jinmantiantang//id//1235377` - 搜索作品ID
- `jm//id//jm1235377` - 使用简称搜索作品ID

### 哔咔漫画
- `picacomic//id//5821859c5f6b9a4f93dbf6eb` - 搜索作品ID
- `pica//id//5821859c5f6b9a4f93dbf6eb` - 使用简称搜索

## 实现方案

### 1. 前缀解析逻辑

在 `MainMenuPage.ets` 中添加前缀解析方法：

```typescript
/**
 * 解析搜索前缀
 * 格式: 图源名称//搜索类型//搜索内容
 * 返回: { sourceName, searchType, query } 或 null
 */
private parseSearchPrefix(input: string): { sourceName: string, searchType: string, query: string } | null {
  const parts = input.split('//');
  if (parts.length === 3) {
    return {
      sourceName: parts[0].trim(),
      searchType: parts[1].trim(),
      query: parts[2].trim()
    };
  }
  return null;
}
```

### 2. 图源名称映射

支持图源全名和简称：

```typescript
private readonly SOURCE_NAME_MAP: Record<string, string> = {
  'pixiv': 'Pixiv',
  'jinmantiantang': '禁漫天堂',
  'jm': '禁漫天堂',
  'picacomic': '哔咔漫画',
  'pica': '哔咔漫画'
};
```

### 3. 搜索类型映射

```typescript
private readonly SEARCH_TYPE_MAP: Record<string, string> = {
  'id': 'searchById',
  'user': 'searchByAuthor',
  'author': 'searchByAuthor'
};
```

### 4. 执行流程

1. 用户在主页面搜索框输入内容
2. 检测是否包含 `//` 分隔符
3. 如果是前缀格式：
   - 解析图源名称、搜索类型、搜索内容
   - 查找对应图源
   - 验证图源是否支持该搜索类型
   - 直接跳转到图源详情页并执行搜索
4. 如果不是前缀格式：
   - 显示图源选择对话框（现有逻辑）
