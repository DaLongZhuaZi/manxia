# 电子书书库显示问题修复说明

## 🔍 问题分析

### 问题现象
用户在"数据管理"页面成功导入PDF电子书后，返回"书库"页面切换到电子书标签，但是显示的总数为0，看不到刚导入的电子书。

### 日志分析
```
11-08 16:08:30.440  ℹ️ [EBookDataManager] 电子书保存成功: 第二次世界大战战史
11-08 16:08:30.440  ℹ️ [DataManagementPage] 电子书导入成功: 第二次世界大战战史
...
11-08 16:08:38.054  🔍 [MainMenuPage] 电子书筛选完成: 总数=0, 筛选后=0, 类型=all
```

### 根本原因
**页面生命周期问题**：

1. **初次加载**：`MainMenuPage` 首次创建时，`aboutToAppear()` 被调用，执行 `loadEBookList()` 加载电子书列表（此时数据库是空的，列表为空）

2. **导入电子书**：用户从 `MainMenuPage` 导航到 `DataManagementPage`，导入电子书成功并保存到数据库

3. **返回书库**：用户返回 `MainMenuPage`，但是：
   - `MainMenuPage` 实例没有被销毁（仍在导航栈中）
   - `aboutToAppear()` **不会**再次调用
   - 电子书列表数据**没有刷新**，仍然是旧的空列表

4. **显示结果**：用户看到的是旧的空列表，导入的电子书不可见

## ✅ 修复方案

### 1. 添加 `onPageShow()` 生命周期方法

**文件**: `entry/src/main/ets/pages/MainMenuPage.ets`

```typescript
/**
 * 页面显示时刷新数据
 */
onPageShow(): void {
  logger.lifecycle(TAG, '📱 页面显示，检查是否需要刷新数据');
  
  // 刷新电子书列表（可能在其他页面导入了新书）
  if (this.libraryContentType === LibraryContentType.EBOOK) {
    logger.info(TAG, '当前在电子书标签，刷新电子书列表');
    this.loadEBookList();
  }
}
```

**作用**：
- 每次页面显示时都会触发
- 检查当前是否在电子书标签
- 如果在电子书标签，重新从数据库加载电子书列表

### 2. 优化内容类型切换逻辑

**文件**: `entry/src/main/ets/pages/MainMenuPage.ets`

```typescript
/**
 * 切换书库内容类型
 */
private toggleLibraryContentType(type: LibraryContentType): void {
  if (this.libraryContentType !== type) {
    this.libraryContentType = type;
    logger.info(TAG, `切换书库内容类型: ${type}`);
    
    // 重置筛选条件
    this.libraryFilterType = LibraryFilterType.ALL;
    
    // 切换到电子书时，刷新列表（可能有新导入的书）
    if (type === LibraryContentType.EBOOK) {
      logger.info(TAG, '切换到电子书，刷新列表');
      this.loadEBookList(); // ← 主动刷新
    } else {
      // 漫画：只应用筛选
      this.applyLibraryFilter();
    }
  }
}
```

**作用**：
- 用户切换到电子书标签时，主动刷新列表
- 确保用户看到最新的电子书数据

## 📝 HarmonyOS 生命周期说明

### Navigation 路由模式下的页面生命周期

```
页面首次加载:
  aboutToAppear() → build()

页面跳转到其他页面:
  onPageHide()  ← 页面隐藏，但未销毁

从其他页面返回:
  onPageShow()  ← 页面重新显示（重要！）

页面销毁:
  aboutToDisappear()
```

### 关键区别
- **aboutToAppear()**：只在页面首次创建时调用一次
- **onPageShow()**：每次页面显示时都会调用（包括返回时）
- **onPageHide()**：页面隐藏时调用（导航到其他页面）

### 最佳实践
✅ **应该在 onPageShow() 中刷新数据**，因为：
1. 数据可能在其他页面被修改
2. 确保用户看到最新的数据
3. 提供更好的用户体验

❌ **不应该只在 aboutToAppear() 中加载数据**，因为：
1. 只会在首次创建时加载一次
2. 后续返回时看到的是旧数据
3. 用户体验差

## 🎯 总结

### 问题原因
**页面生命周期管理不当**，导致数据未及时刷新

### 解决方案
1. 添加 `onPageShow()` 方法实现自动刷新
2. 优化标签切换时的主动刷新逻辑
