# 封面图片提取修复说明

## 🎯 目标
从Komiic网站正确提取漫画封面图片URL（`https://public.komiic.com/comics/.../cover.jpg`）

## 🔍 问题分析

### HTML结构
```html
<div class="ComicCard">
  <a href="/comic/466">
    <div class="v-card-item">
      <div class="ComicCard__image">
        <img class="v-img__img" src="https://public.komiic.com/comics/.../cover.jpg">
      </div>
    </div>
    <div class="v-card-text">
      <span class="text-subtitle-2">膽大黨</span>
    </div>
  </a>
</div>
```

### 提取逻辑
1. **基础选择器**: `.ComicCard` - 选择所有漫画卡片
2. **字段选择器**:
   - `id`: `@href` - 提取链接（相对路径 `/comic/466`）
   - `title`: `.text-subtitle-2::text` - 提取标题文本
   - `cover`: `.ComicCard__image img::attr(src)` - **提取封面图片URL**
   - `status`: `.status::text` - 提取状态
   - `views`: `.Comic_views::text` - 提取浏览量
   - `favorites`: `.ComicCard__favorite::text` - 提取收藏数

## ✅ 修复方案

### 1. JSON配置 (komiic_webview.json)
```json
{
  "type": "extract",
  "selector": ".ComicCard",
  "multiple": true,
  "fields": {
    "id": "@href",
    "title": ".text-subtitle-2::text",
    "cover": ".ComicCard__image img::attr(src)",
    "status": ".status::text",
    "views": ".Comic_views::text",
    "favorites": ".ComicCard__favorite::text"
  }
}
```

**关键点**:
- 使用 `.ComicCard__image img` 定位到img标签
- 使用 `::attr(src)` 提取src属性

### 2. 选择器引擎 (MangaSourceActionEngine.ets)

#### parseFieldSelector方法
```typescript
private parseFieldSelector(fieldSelector: string): FieldSelectorParseResult {
  // 处理 ::attr(name)
  const attrMatch = fieldSelector.match(/(.+)::attr\(([^)]+)\)/);
  if (attrMatch) {
    return { 
      selector: attrMatch[1].trim(),  // ".ComicCard__image img"
      extractor: `attr:${attrMatch[2]}`  // "attr:src"
    };
  }
  // ...
}
```

#### buildMultipleItemsScript方法
```typescript
private buildMultipleItemsScript(baseSelector: string, fields: Array<[string, string]>): string {
  const fieldExtractions = fields.map((field: [string, string]) => {
    const [fieldName, fieldSelector] = field;
    const parsed = this.parseFieldSelector(fieldSelector);
    const cleanSelector = parsed.selector;  // ".ComicCard__image img"
    const extractor = parsed.extractor;     // "attr:src"
    
    let extractCode = '';
    if (extractor.startsWith('attr:')) {
      const attrName = extractor.substring(5);  // "src"
      extractCode = cleanSelector
        ? `item.querySelector('${cleanSelector}')?.getAttribute('${attrName}') || ''`
        : `item.getAttribute('${attrName}') || ''`;
    }
    
    return `${fieldName}: ${extractCode}`;
  }).join(',\n');
  
  // 生成JavaScript代码
  return `
    (function() {
      const items = Array.from(document.querySelectorAll('${baseSelector}'));
      return items.map(item => ({
        ${fieldExtractions}
      }));
    })()
  `;
}
```

**生成的JavaScript代码**:
```javascript
(function() {
  const items = Array.from(document.querySelectorAll('.ComicCard'));
  return items.map(item => ({
    id: item.getAttribute('href') || '',
    title: item.querySelector('.text-subtitle-2')?.textContent?.trim() || '',
    cover: item.querySelector('.ComicCard__image img')?.getAttribute('src') || '',
    status: item.querySelector('.status')?.textContent?.trim() || '',
    views: item.querySelector('.Comic_views')?.textContent?.trim() || '',
    favorites: item.querySelector('.ComicCard__favorite')?.textContent?.trim() || ''
  }));
})()
```

## ⚠️ 注意事项

1. **嵌套查询**: 使用`item.querySelector()`在每个`.ComicCard`内部查找元素
2. **可选链**: 使用`?.`防止null错误
3. **默认值**: 使用`|| ''`提供空字符串默认值
4. **WebView控制器**: 必须先在`SourceDetailPage`中初始化，然后才能在`MangaDetailPage`中使用
