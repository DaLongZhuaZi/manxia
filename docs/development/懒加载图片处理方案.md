# 懒加载图片处理方案

## 🎯 问题诊断

### 现象
所有漫画的`cover`字段都是空字符串，即使HTML中明确存在：
```html
<img class="v-img__img" src="https://public.komiic.com/comics/.../cover.jpg">
```

### 根本原因
**Komiic使用懒加载技术**：
- 页面初始加载时，视口外的图片`src`可能为空或占位符
- 只有当图片滚动到视口内时，才会设置真实的`src`
- 我们的提取操作在图片加载前就执行了

## ✅ 解决方案

### 1. 增加等待时间
```json
{
  "type": "wait",
  "condition": "time",
  "duration": 3000,
  "description": "等待页面初始加载"
}
```

### 2. 触发懒加载
```json
{
  "type": "script",
  "code": "window.scrollTo(0, document.body.scrollHeight); window.scrollTo(0, 0);",
  "description": "滚动页面触发懒加载图片"
}
```

**原理**:
- `scrollTo(0, document.body.scrollHeight)` - 滚动到页面底部
- `scrollTo(0, 0)` - 滚动回顶部
- 这个过程会触发所有图片进入视口，激活懒加载

### 3. 等待图片加载
```json
{
  "type": "wait",
  "condition": "time",
  "duration": 3000,
  "description": "等待图片懒加载完成"
}
```

## 🔄 替代方案

如果滚动方案不work，可以尝试：

### 方案A: 使用Intersection Observer
```javascript
// 等待所有图片进入视口
await new Promise(resolve => {
  const images = document.querySelectorAll('.ComicCard__image img');
  let loaded = 0;
  images.forEach(img => {
    if (img.complete) loaded++;
    else img.addEventListener('load', () => {
      loaded++;
      if (loaded === images.length) resolve();
    });
  });
  if (loaded === images.length) resolve();
});
```

### 方案B: 强制设置src
```javascript
// 从data-src复制到src
document.querySelectorAll('.ComicCard__image img').forEach(img => {
  if (!img.src && img.dataset.src) {
    img.src = img.dataset.src;
  }
});
```

### 方案C: 直接从style提取
如果图片使用background-image：
```json
"cover": ".ComicCard__image::attr(style)"
```
然后解析`background-image: url(...)`
