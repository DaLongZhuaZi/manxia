## Komiic图源示例

### 元数据
```json
{
  "id": "komiic",
  "name": "Komiic",
  "version": "1.0.0",
  "language": "zh-CN",
  "baseUrl": "https://komiic.com"
}
```

### 核心功能
1. **热门列表** - GraphQL查询最近更新
2. **最新更新** - 按时间排序
3. **搜索** - 关键词搜索
4. **漫画详情** - 包含章节列表
5. **章节图片** - 图片URL列表

### 技术特点
- 使用GraphQL API
- 需要特定的Referer头
- 支持分页（offset方式）
- 图片需要特殊请求头

## 技术挑战

### 1. JSONPath实现
**挑战**: HarmonyOS可能没有现成的JSONPath库

**解决方案**:
- 自己实现简化版JSONPath
- 支持基本的路径表达式
- 或引入第三方库

### 2. HTML解析
**挑战**: 需要CSS选择器支持

**解决方案**:
- 使用WebView的DOM API
- 实现简单的选择器解析器
- 或限制只支持JSON API

### 3. 变量替换
**挑战**: 需要模板引擎

**解决方案**:
- 实现简单的{{variable}}替换
- 支持嵌套变量
- 支持条件表达式（可选）

### 4. 速率限制
**挑战**: 需要实现令牌桶算法

**解决方案**:
- 实现简单的速率限制器
- 支持突发请求
- 支持全局和per-source限制

## 与Tachiyomi的对比

### 相似之处
- 插件化设计
- 支持多种数据源
- 统一的API接口
- 可扩展性

### 不同之处
| 特性 | Tachiyomi | ManXia |
|------|-----------|--------|
| 格式 | Kotlin代码 | JSON配置 |
| 复杂度 | 高 | 低 |
| 学习曲线 | 陡峭 | 平缓 |
| 灵活性 | 非常高 | 中等 |
| 维护性 | 需要编译 | 即时生效 |
| JavaScript | 支持 | 待实现 |
| HTML解析 | 完整支持 | 待实现 |

## 优势

1. **易于开发**: 无需编写代码，只需配置JSON
2. **易于分享**: JSON文件可直接分享
3. **易于维护**: 配置清晰，修改简单
4. **安全性**: 不执行任意代码
5. **跨平台**: JSON格式通用

## 限制

1. **功能受限**: 不支持复杂逻辑
2. **无JavaScript**: 不能执行JS代码
3. **反爬虫**: 难以对抗复杂的反爬虫
4. **加密**: 不支持自定义解密算法
