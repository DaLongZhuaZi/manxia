# 存储管理系统说明文档

## 概述

已为应用创建了统一的存储管理系统，包括：
1. **StorageAnalyzer** - 存储分析器，统一管理所有存储使用情况
2. **StorageManagementPage** - 存储管理页面，可视化展示和管理存储

## 一、StorageAnalyzer 存储分析器

### 位置
`entry/src/main/ets/Framework/Storage/StorageAnalyzer.ets`

### 功能特性

#### 1. 存储类型分类
```typescript
export enum StorageType {
  IMAGE_CACHE,        // 图片缓存（内存+磁盘）
  WEBVIEW_CACHE,      // WebView缓存
  DATABASE,           // 数据库文件
  COMIC_FILES,        // 漫画文件
  COVER_FILES,        // 封面文件
  CHAPTER_FILES,      // 章节文件
  TEMP_FILES,         // 临时文件
  PLUGIN_FILES        // 插件文件
}
```

#### 2. 核心方法

**分析存储使用情况**
```typescript
const analyzer = StorageAnalyzer.getInstance();
const statistics = await analyzer.analyzeStorage(forceRefresh);

// 返回的统计信息包括：
// - totalSize: 总大小
// - usedSize: 已使用大小
// - items: 各存储项详情数组
// - lastUpdateTime: 最后更新时间
```

**清理存储**
```typescript
const options: ClearOptions = {
  types: [StorageType.IMAGE_CACHE, StorageType.TEMP_FILES],
  olderThan: 7 * 24 * 60 * 60 * 1000  // 清理7天前的文件（可选）
};

const result = await analyzer.clearStorage(options);
// result包含：success, clearedSize, clearedCount, errors
```

**格式化大小**
```typescript
const sizeStr = analyzer.formatSize(1024 * 1024); // "1.00 MB"
```

#### 3. 存储项信息结构

每个存储项包含以下信息：
```typescript
interface StorageItem {
  type: StorageType;          // 类型
  name: string;               // 名称
  description: string;        // 描述
  size: number;               // 大小（字节）
  fileCount: number;          // 文件数量
  path: string;               // 存储路径
  canClear: boolean;          // 是否可清理
  lastModified: number;       // 最后修改时间
}
```

### 存储项说明

| 类型 | 名称 | 描述 | 可清理 |
|------|------|------|--------|
| IMAGE_CACHE | 图片缓存 | 内存和磁盘图片缓存 | ✅ |
| WEBVIEW_CACHE | WebView缓存 | 漫画详情和章节列表缓存 | ✅ |
| DATABASE | 数据库 | 漫画数据、阅读历史、收藏等 | ❌ |
| COMIC_FILES | 漫画文件 | 本地导入的漫画 | ❌ |
| COVER_FILES | 封面文件 | 漫画封面图片 | ✅ |
| CHAPTER_FILES | 章节文件 | 已下载的漫画章节 | ❌ |
| TEMP_FILES | 临时文件 | 临时缓存和处理文件 | ✅ |
| PLUGIN_FILES | 插件文件 | 图源插件和扩展 | ❌ |

## 二、StorageManagementPage 存储管理页面

### 位置
`entry/src/main/ets/pages/StorageManagementPage.ets`

### 页面功能

1. **存储总览**
   - 显示总使用空间
   - 进度条可视化
   - 存储项数量统计

2. **存储项列表**
   - 显示所有存储项的详细信息
   - 支持多选（仅可清理项）
   - 显示大小、文件数量、描述

3. **操作功能**
   - 刷新统计信息
   - 批量清理选中项
   - 实时反馈清理结果

### 使用方法

#### 1. 在路由配置中注册页面

在 `entry/src/main/ets/pages/Index.ets` 或相应的路由配置文件中添加：

```typescript
import { StorageManagementPage } from './StorageManagementPage';

// 在NavPathStack中注册
@Builder

}

// 导航到页面
this.pathStack.pushPathByName('StorageManagementPage', null);
```

#### 2. 从设置页面跳转

在设置页面添加入口：

```typescript
ListItem() {

```

### 2. 添加定时清理

```typescript

public scheduleAutoCleanup(interval: number, options: ClearOptions): void {
  setInterval(async () => {
    await this.clearStorage(options);
  }, interval);
}
```

### 3. 添加存储预警

```typescript
// 当存储空间超过阈值时提醒用户
if (statistics.usedSize > STORAGE_WARNING_THRESHOLD) {
  promptAction.showDialog({
    title: '存储空间不足',
    message: '建议清理缓存释放空间'
  });
}
```

### 4. 导出存储报告

```typescript
// 生成存储使用报告
public async exportStorageReport(): Promise<string> {
  const statistics = await this.analyzeStorage(true);
  const report = {
    timestamp: Date.now(),
    totalSize: statistics.usedSize,
    items: statistics.items.map(item => ({
      name: item.name,
      size: this.formatSize(item.size),
      fileCount: item.fileCount
    }))
  };
  return JSON.stringify(report, null, 2);
}
```

## 六、注意事项

1. **数据安全**：不可清理的项（如数据库、用户文件）已标记为 `canClear: false`
2. **性能优化**：存储分析结果会缓存30秒，避免频繁扫描
3. **错误处理**：所有清理操作都有完整的错误处理和用户反馈
4. **权限要求**：确保应用有文件读写权限
