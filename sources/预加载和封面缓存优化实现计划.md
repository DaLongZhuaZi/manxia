#### 2.2.3 图源详情页集成
**文件**: `SourceDetailPage.ets`

修改点：
1. 在加载漫画列表后，保存到`temp_manga_info`表
2. 显示封面前，先检查是否有本地缓存
3. 如有缓存，直接使用本地路径
4. 如无缓存，显示网络图片，同时后台下载

```typescript
// 伪代码
async loadComics() {
  const comics = await this.engine.getPopular();
  
  for (const comic of comics) {
    // 保存临时漫画信息
    await coverCacheManager.saveTempManga(
      this.sourceId,
      comic.id,
      comic.title,
      comic.coverUrl
    );
    
    // 检查本地缓存
    const localPath = await coverCacheManager.getLocalCoverPath(
      this.sourceId,
      comic.id
    );
    
    if (localPath) {
      comic.coverLocalPath = localPath;
    } else {
      // 后台下载
      coverCacheManager.downloadAndCacheCover({...}).catch(() => {});
    }
  }
}
```
