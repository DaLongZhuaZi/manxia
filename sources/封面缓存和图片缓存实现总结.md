# 封面缓存和图片缓存实现总结

## ✅ 已完成的功能

### 1. 封面缓存管理器 (`CoverCacheManager.ets`)

#### 功能特性
- **临时漫画信息存储**: 保存漫画名称和封面URL到数据库
- **封面本地缓存**: 下载封面到本地，按图源分类存储
- **智能缓存复用**: 第二次访问直接使用本地缓存
- **过期清理**: 支持清理N天未访问的封面
- **按图源管理**: 可以查看和删除指定图源的所有封面

#### 存储结构
```
/data/storage/el2/base/haps/entry/files/covers/
  ├── source_1/           # 图源1的封面
  │   ├── manga_abc.jpg
  │   └── manga_def.jpg
  ├── source_2/           # 图源2的封面
  │   └── manga_xyz.jpg
  └── ...
```

#### 核心方法
```typescript
// 保存临时漫画信息
async saveTempManga(sourceId, externalId, title, coverUrl)

// 获取本地封面路径
async getLocalCoverPath(sourceId, externalId)

// 下载并缓存封面
async downloadAndCacheCover(sourceId, externalId, coverUrl, headers)

// 获取图源封面统计
async getSourceCoverStats(sourceId)

// 删除图源所有封面
async deleteSourceCovers(sourceId)

// 清理过期封面
async cleanupExpiredCovers(daysToKeep)
```

### 2. 永久图片缓存管理器 (`PermanentImageCacheManager.ets`)

#### 功能特性
- **双缓存模式**: 
  - **永久缓存**: 开启"边看边下载"时使用，不会被清理
  - **临时缓存**: 未开启时使用，受最大缓存大小限制
- **智能缓存清理**: 临时缓存超出限制时，自动清理最旧的文件
- **按漫画统计**: 可以查看每个漫画的缓存占用
- **精准删除**: 支持删除指定漫画的所有缓存

#### 存储结构
```
永久缓存:
/data/storage/el2/base/haps/entry/files/permanent_cache/
  ├── source_1/
  │   ├── manga_abc/
  │   │   ├── chapter_001/
  │   │   │   ├── page_0.jpg
  │   │   │   ├── page_1.jpg
  │   │   │   └── ...
  │   │   └── chapter_002/
  │   └── manga_def/
  └── source_2/

临时缓存:
/data/storage/el2/base/haps/entry/cache/temp_image_cache/
  └── (相同结构)
```

#### 核心方法
```typescript
// 获取图源缓存配置
async getSourceCacheConfig(sourceId)

// 保存图片到缓存（自动选择永久/临时）
async saveImageToCache(sourceId, mangaId, chapterId, pageIndex, imageUrl, imageData)

// 获取缓存的图片路径
async getCachedImagePath(sourceId, mangaId, chapterId, pageIndex, imageUrl)

// 获取图源的漫画缓存统计
async getSourceMangaCacheStats(sourceId)

// 删除漫画缓存
async deleteMangaCache(sourceId, mangaId)
```

### 3. 数据库扩展

#### 新增表: `temp_manga_info`
```sql
CREATE TABLE IF NOT EXISTS temp_manga_info (
  id TEXT PRIMARY KEY,                -- sourceId_externalId
  sourceId INTEGER NOT NULL,          -- 图源ID
  externalId TEXT NOT NULL,           -- 外部漫画ID
  title TEXT NOT NULL,                -- 漫画名称
  coverUrl TEXT NOT NULL,             -- 原始封面URL
  localCoverPath TEXT,                -- 本地封面路径
  createTime INTEGER NOT NULL,        -- 创建时间
  lastAccessTime INTEGER NOT NULL,    -- 最后访问时间
  UNIQUE(sourceId, externalId)
)
```

新增字段：
- `downloadWhileReading INTEGER DEFAULT 1` - 是否开启边看边下载
- `maxCacheSize INTEGER DEFAULT 1073741824` - 最大缓存大小（默认1GB）

## 📋 待集成的功能

### 1. 图源详情页集成封面缓存

**文件**: `SourceDetailPage.ets`

**需要修改的地方**:
1. 在加载漫画列表后，调用`CoverCacheManager.saveTempManga()`保存信息
2. 显示封面前，调用`CoverCacheManager.getLocalCoverPath()`检查缓存
3. 如有缓存，使用本地路径；否则显示网络图片并后台下载

**示例代码**:
```typescript
import { CoverCacheManager } from '../Framework/Cache/CoverCacheManager';

async loadComics() {
  const coverCache = CoverCacheManager.getInstance();
  const comics = await this.engine.getPopular();
  
  for (const comic of comics) {
    // 保存临时漫画信息
    await coverCache.saveTempManga(
      this.sourceId,
      comic.id,
      comic.title,
      comic.coverUrl
    );
    
    // 检查本地缓存
    const localPath = await coverCache.getLocalCoverPath(
      this.sourceId,
      comic.id
    );
    
    if (localPath) {
      comic.coverLocalPath = localPath;
    } else {
      // 后台下载（不阻塞UI）
      coverCache.downloadAndCacheCover(
        this.sourceId,
        comic.id,
        comic.coverUrl,
        this.networkHeaders
      ).catch(() => {});
    }
  }
}
```

### 2. 阅读器集成图片缓存

**文件**: `MangaViewer.ets` 或 `ImageCacheManager.ets`

**需要修改的地方**:
1. 在下载图片后，调用`PermanentImageCacheManager.saveImageToCache()`
2. 加载图片前，先调用`getCachedImagePath()`检查缓存
3. 如有缓存，直接使用本地文件

**示例代码**:
```typescript
import { PermanentImageCacheManager } from '../Framework/Cache/PermanentImageCacheManager';

async loadImage(page: MangaPage) {
  const imageCache = PermanentImageCacheManager.getInstance();
  
  // 先检查缓存
  const cachedPath = await imageCache.getCachedImagePath(
    this.sourceId,
    this.mangaId,
    this.chapterId,
    page.index,
    page.imageUrl
  );
  
  if (cachedPath) {
    // 使用缓存
    return this.loadFromLocal(cachedPath);
  }
  
  // 下载图片
  const imageData = await this.downloadImage(page.imageUrl);
  
  // 保存到缓存
  await imageCache.saveImageToCache(
    this.sourceId,
    this.mangaId,
    this.chapterId,
    page.index,
    page.imageUrl,
    imageData
  );
  
  return imageData;
}
```

## 📊 数据流程

### 封面缓存流程
```
用户访问图源详情页
    ↓
加载漫画列表
    ↓
保存到temp_manga_info表
    ↓
检查是否有本地封面
    ↓
有 → 使用本地路径
    ↓
无 → 显示网络图片 + 后台下载
    ↓
下载完成 → 更新localCoverPath
    ↓
下次访问直接使用本地缓存
```

### 图片缓存流程
```
用户阅读漫画
    ↓
加载图片
    ↓
检查是否有缓存
    ↓
有 → 直接使用
    ↓
无 → 下载图片
    ↓
获取图源配置
    ↓
downloadWhileReading=true → 保存到永久缓存
downloadWhileReading=false → 保存到临时缓存
    ↓
临时缓存超限 → 清理最旧文件
    ↓
下次加载直接使用缓存
```
