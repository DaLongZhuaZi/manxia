# 在线漫画阅读器问题分析与解决方案

## 问题描述

在线加载未下载的网络漫画时出现两个主要问题：
1. **很长时间的黑屏加载** - 用户体验差
2. **卷页动画降级为普通滑动动画** - 来回翻页几次后卷页效果失效

---

## 问题1：黑屏加载时间过长

### 根本原因

#### 1.1 网络图片加载流程复杂

从`MangaViewer.ets`的`ensurePixelMapLoaded`函数（line 4291-4416）可以看到：

```typescript
private async ensurePixelMapLoaded(page: MangaPage): Promise<void> {
  // ... 检查缓存 ...
  
  if (page.sourceType === ImageSourceType.NETWORK) {
    // 并发控制：最多同时加载MAX_NETWORK_CONCURRENCY张图片
    if (this.networkLoadInProgress >= this.MAX_NETWORK_CONCURRENCY) {
      // 超过并发限制，加入队列等待
      this.pendingNetworkLoads.push(page.id);
      return;
    }
    
    this.networkLoadInProgress++;
    try {
      // 通过ImageCacheManager加载网络图片
      const pm: image.PixelMap | null = await cacheManager.loadImage(page.imageUrl, opts);
      // ... 处理加载结果 ...
    } finally {
      this.networkLoadInProgress--;
      // 处理队列中的下一张图片
    }
  }
}
```

**问题点**：
- 网络图片需要经过HTTP请求 → 下载 → 解码 → 转换为PixelMap的完整流程
- 并发控制限制了同时加载的图片数量
- 在线漫画没有本地缓存，每次都需要完整的网络加载流程

#### 1.2 卷页动画需要PixelMap就绪

从`MangaViewer.ets`的`startCurlPageTurn`函数（line 1904-1939）可以看到：

```typescript
private startCurlPageTurn(targetIndex: number, isForward: boolean): void {
  // 获取当前页的PixelMap
  this.curlCurrentPixelMap = this.pagePixelMaps.get(currentPage.id) || null;
  
  // 获取目标页的PixelMap
  this.curlNextPixelMap = this.pagePixelMaps.get(targetPage.id) || null;
  
  // 检查当前页PixelMap是否已加载
  if (!this.curlCurrentPixelMap) {
    logger.warn(TAG, `当前页PixelMap未加载，尝试同步加载`);
    // 尝试同步等待加载
    this.ensurePixelMapLoaded(currentPage).then(() => {
      this.curlCurrentPixelMap = this.pagePixelMaps.get(currentPage.id) || null;
      if (this.curlCurrentPixelMap) {
        this.executeCurlAnimation(targetIndex, isForward);
      } else {
        // 仍然无法加载，回退到普通翻页
        this.fallbackToNormalPageTurn(targetIndex, isForward);
      }
    });
    // 先复位位置
    this.animateToPosition(0, 0);
    return;
  }
  
  // 执行卷页动画
  this.executeCurlAnimation(targetIndex, isForward);
}
```

**问题点**：
- 卷页动画**必须**等待当前页和下一页的PixelMap都加载完成
- 如果PixelMap未加载，会触发同步等待加载
- 在等待期间，用户看到的是黑屏或Loading状态

#### 1.3 WebView图源的额外延迟

从之前的分析可知，WebView图源（如拷贝漫画）的页面列表获取流程：
1. 导航到章节页面：1500ms
2. 等待页面初始化：2000ms → 优化后1500ms
3. 执行JavaScript收集图片：4000-5000ms → 优化后4000ms
4. **总计：6.5-8秒才能获取到图片URL列表**

然后才开始下载每张图片：
- HTTP请求：200-1000ms（取决于网络）
- 下载图片：500-3000ms（取决于图片大小和网络速度）
- 解码为PixelMap：100-500ms

**单张图片总耗时：0.8-4.5秒**

// 为加载队列添加优先级机制
private pendingNetworkLoads: Array<{id: string, priority: number}> = [];

private async ensurePixelMapLoaded(page: MangaPage): Promise<void> {
  // ... 前置检查 ...
  
  if (this.networkLoadInProgress >= this.MAX_NETWORK_CONCURRENCY) {
    const alreadyQueued = this.pendingNetworkLoads.find(item => item.id === page.id);
    if (!alreadyQueued) {
      // 根据页面位置计算优先级
      const priority = this.calculateLoadPriority(page);
      this.pendingNetworkLoads.push({id: page.id, priority: priority});
      
      // 按优先级排序队列
      this.pendingNetworkLoads.sort((a, b) => b.priority - a.priority);
    }
    return;
  }
  
  // ... 加载逻辑 ...
}

private calculateLoadPriority(page: MangaPage): number {
  const currentIndex = this.viewCurrentPageIndex;
  const pageIndex = page.index;
  const distance = Math.abs(pageIndex - currentIndex);
  
  // 距离越近，优先级越高
  return 100 - distance;
}

private startCurlPageTurn(targetIndex: number, isForward: boolean): void {
  const currentIndex: number = this.viewCurrentPageIndex;
  
  // 获取PixelMap
  const currentPage: MangaPage = this.chapter.pages[currentIndex];
  this.curlCurrentPixelMap = this.pagePixelMaps.get(currentPage.id) || null;
  
  const targetPage: MangaPage = this.chapter.pages[targetIndex];
  this.curlNextPixelMap = this.pagePixelMaps.get(targetPage.id) || null;
  
  // 新增：如果当前页PixelMap未加载，给予更长的等待时间
  if (!this.curlCurrentPixelMap) {
    logger.warn(TAG, `当前页PixelMap未加载，开始加载并等待`);
    
    // 显示Loading状态
    this.isPageTurning = true;
    this.pageTurnOpacity = 0.5; // 半透明显示当前页
    
    // 设置超时时间为3秒（而不是立即降级）
    const loadTimeout = setTimeout(() => {
      logger.error(TAG, `PixelMap加载超时，降级到普通翻页`);
      this.fallbackToNormalPageTurn(targetIndex, isForward);
    }, 3000);
    
    // 尝试加载
    this.ensurePixelMapLoaded(currentPage).then(() => {
      clearTimeout(loadTimeout);
      this.curlCurrentPixelMap = this.pagePixelMaps.get(currentPage.id) || null;
      
      if (this.curlCurrentPixelMap) {
        // 加载成功，执行卷页动画
        this.executeCurlAnimation(targetIndex, isForward);
      } else {
        // 加载失败，降级
        this.fallbackToNormalPageTurn(targetIndex, isForward);
      }
    }).catch(() => {
      clearTimeout(loadTimeout);
      this.fallbackToNormalPageTurn(targetIndex, isForward);
    });
    
    return;
  }
  
  // 如果下一页PixelMap未加载，不影响卷页动画启动
  // 卷页动画可以显示空白的下一页
  if (!this.curlNextPixelMap) {
    logger.info(TAG, `下一页PixelMap未加载，后台加载中`);
    this.ensurePixelMapLoaded(targetPage).then(() => {
      this.curlNextPixelMap = this.pagePixelMaps.get(targetPage.id) || null;
    });
  }
  
  // 执行卷页动画
  this.executeCurlAnimation(targetIndex, isForward);
}
