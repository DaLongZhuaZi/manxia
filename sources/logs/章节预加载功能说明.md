# 章节预加载功能实现说明

## 功能概述

实现了智能章节预加载功能，在用户浏览漫画详情页时，后台自动预加载接下来要阅读的章节的页面列表和前3页图片，显著减少首图加载时间。

## 核心组件

### 1. ChapterPreloadManager（章节预加载管理器）

**位置**: `entry/src/main/ets/Framework/Preload/ChapterPreloadManager.ets`

**功能**:
- 管理章节预加载任务队列
- 控制并发数（默认1个任务）
- 检测阅读器状态，避免与正常阅读冲突
- 为每个章节预加载前N页图片（默认3页）

**关键方法**:
```typescript
// 启动预加载
startPreload(mangaId, externalMangaId, sourceId, chapters)

// 设置阅读器活跃状态
setReaderActive(active: boolean)

// 检查章节是否已预加载
isChapterPreloaded(chapterId: string): boolean

// 获取已预加载的页面数
getPreloadedPageCount(chapterId: string): number
```

### 2. ImageCacheManager扩展

**新增方法**: `preloadImage(url, options)`

**功能**: 后台下载图片到缓存，不返回PixelMap，用于预加载场景

## 工作流程

### 1. 漫画详情页触发预加载

**时机**: 章节列表加载完成后1秒

**逻辑**:
1. 检查是否有阅读进度
2. 如果有进度，从进度后的章节开始预加载
3. 如果无进度，从第一章开始预加载
4. 选择前3个章节进行预加载

**代码位置**: `MangaDetailPage.ets`
- `triggerChapterPreload()`: 触发预加载
- `loadMangaDataWithWebView()`: 在章节加载完成后调用

### 2. 阅读器状态管理

**阅读器激活时**:
- `MangaDetailPage.startReading()`: 用户点击"开始/继续阅读"时
- `MangaReaderPage.onPageShow()`: 阅读器页面显示时
- 效果: 暂停所有预加载任务

**阅读器关闭时**:
- `MangaReaderPage.aboutToDisappear()`: 阅读器页面关闭时
- 效果: 恢复预加载任务

### 3. 预加载执行

**每个章节的预加载流程**:
1. 调用`MangaSourceEngine.getPageList()`获取页面列表
2. 将页面信息保存到数据库（`online_page`表）
3. 使用`ImageCacheManager.preloadImage()`下载前3页图片
4. 图片自动缓存到`OnlineImageLoader`的内存缓存中

**并发控制**:
- 默认同时只处理1个预加载任务
- 可通过`setConfig()`调整并发数和预加载页数

## 优化效果

### 问题①：首图加载慢（已优化）

**优化前**:
- 总耗时: 22.9秒
  - 页面初始化: 3.6秒
  - 获取页面列表: 6.6秒
  - 首图下载: 12.5秒

**优化后**:
- JSON配置优化: 页面列表获取从6.6秒降至2-3秒
- 预加载: 如果章节已预加载，首图加载时间接近0秒（直接从缓存读取）

**预期效果**:
- 首次进入: ~18-19秒（减少4-5秒）
- 预加载命中: ~3-5秒（减少17-18秒）

### 问题②：翻页后短暂显示旧页面（已修复）

**问题原因**: 翻页时先更新UI，然后才异步加载PixelMap

**修复方案**: 在翻页前检查目标页面的PixelMap是否已加载
- 已加载: 立即翻页
- 未加载: 先加载PixelMap，完成后再翻页

**修复位置**: `MangaViewer.ets`
- TTB模式（上下翻页）
- LTR模式（左右翻页）
- RTL模式（右左翻页）

## 使用示例

### 配置预加载参数

```typescript
const preloadManager = ChapterPreloadManager.getInstance();

// 设置预加载配置
preloadManager.setConfig({
  maxConcurrentTasks: 2,    // 最大并发任务数
  preloadPageCount: 5,      // 每个章节预加载页数
  enabled: true             // 启用预加载
});
```

### 检查预加载状态

```typescript
const preloadManager = ChapterPreloadManager.getInstance();

// 检查章节是否已预加载
if (preloadManager.isChapterPreloaded(chapterId)) {
  logger.info('章节已预加载');
}

// 获取已预加载的页面数
const preloadedCount = preloadManager.getPreloadedPageCount(chapterId);
logger.info(`已预加载 ${preloadedCount} 页`);

// 获取所有任务状态
const allTasks = preloadManager.getAllTasks();
allTasks.forEach(task => {
  logger.info(`章节: ${task.chapterTitle}, 状态: ${task.status}, 进度: ${task.preloadedPages}/${task.pageCount}`);
});
```

## 注意事项

1. **避免冲突**: 预加载管理器会自动检测阅读器状态，避免与正常阅读冲突

2. **资源控制**: 默认配置较保守（1个并发，3页预加载），可根据设备性能调整

3. **网络消耗**: 预加载会消耗网络流量，建议在WiFi环境下使用

4. **缓存管理**: 预加载的图片会占用内存缓存，`OnlineImageLoader`会自动管理缓存大小

5. **数据库**: 页面列表信息会保存到`online_page`表，避免重复请求

## 未来优化方向

1. **智能预测**: 根据用户阅读习惯预测下一章
2. **网络状态感知**: WiFi下预加载更多，移动网络下减少预加载
3. **优先级调整**: 根据章节距离调整预加载优先级
4. **后台任务**: 使用系统后台任务API实现更高效的预加载
5. **缩略图预加载**: 先加载低分辨率缩略图，再加载高清图

## 测试建议

1. **首次进入测试**: 清除缓存后进入漫画详情页，观察预加载日志
2. **预加载命中测试**: 等待预加载完成后进入阅读器，观察首图加载时间
3. **翻页测试**: 在预加载范围内翻页，验证是否还有闪回
4. **并发测试**: 调整并发数，观察性能影响
5. **网络测试**: 在不同网络环境下测试预加载效果
