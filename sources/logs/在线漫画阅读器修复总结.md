## 已完成的修复

### 修复1：保护相邻页PixelMap不被清理 ✅

**文件**：`MangaViewer.ets` (line 4479-4530)

**问题**：
- `cleanupInvisiblePixelMaps`函数会清理不可见的PixelMap
- 快速翻页时，相邻页的PixelMap被清理
- 下次翻页时发现PixelMap不存在，触发降级

**修复**：
```typescript
// 保护当前页 ± 2页的PixelMap
const protectedIndices = new Set<number>();
const currentIndex = this.viewCurrentPageIndex;

for (let i = Math.max(0, currentIndex - 2); 
     i <= Math.min(totalPagesCount - 1, currentIndex + 2); 
     i++) {
  protectedIndices.add(i);
}

// 跳过受保护的页面
if (protectedIndices.has(idx)) {
  continue;
}
```

**效果**：
- ✅ 确保卷页动画所需的PixelMap始终可用
- ✅ 防止快速翻页导致的动画降级
- ✅ 添加日志：`清理了X个不可见PixelMap，保护了Y个相邻页`

### 修复4：卷页动画容错机制 ✅

**文件**：`MangaViewer.ets` (line 1917-1977)

**问题**：
- PixelMap未加载时立即降级到普通翻页
- 用户看到黑屏或动画突然变化

**修复**：

#### 4.1 增加3秒等待时间
```typescript
// 【修复】设置3秒超时（而不是立即降级）
const loadTimeout = setTimeout(() => {
  logger.error(TAG, `PixelMap加载超时，降级到普通翻页`);
  this.isPageTurning = false;
  this.pageTurnOpacity = 1.0;
  this.fallbackToNormalPageTurn(targetIndex, isForward);
}, 3000); // 3秒超时
```

#### 4.2 显示Loading状态
```typescript
// 【修复】显示Loading状态，避免黑屏
this.isPageTurning = true;
this.pageTurnOpacity = 0.5; // 半透明显示当前页
```

#### 4.3 允许下一页后台加载
```typescript
// 【修复】如果下一页PixelMap未加载，不影响卷页动画启动
// 卷页动画可以显示空白的下一页，后台继续加载
if (!this.curlNextPixelMap) {
  logger.info(TAG, `下一页PixelMap未加载，后台加载中`);
  this.ensurePixelMapLoaded(targetPage).then(() => {
    this.curlNextPixelMap = this.pagePixelMaps.get(targetPage.id) || null;
  });
}
```

**效果**：
- ✅ 给予PixelMap充足的加载时间（3秒）
- ✅ 显示半透明状态而不是黑屏
- ✅ 下一页可以后台加载，不阻塞动画启动
- ✅ 只有在真正超时时才降级
