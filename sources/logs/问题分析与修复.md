# 拷贝漫画WebView图源问题分析与修复

## 问题概述

拷贝漫画WebView图源存在三个主要问题：
1. **加载时间超级长** - 每个阶段都需要3-8秒
2. **章节信息获取失败** - 返回DEBUG数据而不是真实章节
3. **页面列表URL拼接错误** - 导致无法加载漫画图片

---

## 问题1：加载时间过长

### 原因分析

每个workflow都包含大量固定等待时间：

**图源详情页（热门漫画）**：
- navigate: 1000ms
- wait: 1500ms  
- scroll + wait: 500ms
- scroll + wait: 500ms
- **总计：~3.5秒/次**

**漫画详情页**：
- navigate: 1000ms
- wait: 1500ms
- scroll + wait: 500ms
- script执行
- **总计：~3秒**

**章节页面列表**：
- navigate: 1000ms
- wait: 2000ms
- script异步收集
- wait: 5000ms
- **总计：~8秒/次**

### 修复方案

优化等待时间，基于实际页面加载速度：
- `getChapterList`: 1000ms → 800ms, 500ms → 400ms
- `getMangaDetail`: 1500ms → 1200ms
- `getMangaDetailWithChapters`: 1500ms → 1200ms, 500ms → 400ms
- `getPageList`: 2000ms → 1500ms, 5000ms → 4000ms

**预期提升**：
- 图源详情页：3.5秒 → 2.8秒（节省20%）
- 漫画详情页：3秒 → 2.4秒（节省20%）
- 章节页面：8秒 → 6.5秒（节省19%）

## 问题2：章节信息获取失败

### 问题表现

从日志可以看到：
```
章节原始数据: externalId=DEBUG, title=Total:17 Samples:/|/comics|/topic|/filter|/rank|/download|...
```

这表明章节提取脚本返回了DEBUG信息，而不是真实章节。

### 原因分析

查看`getChapterList`的JavaScript代码（line 572-574）：

```javascript
const selectors = [
  '.chapter-list-1 ul li a',
  '.chapter-list ul li a', 
  'ul.chapter-list li a',
  'a[href*="/chapter/"]'
];
```

这些选择器都无法匹配当前网站的DOM结构。当所有选择器都失败时，脚本返回DEBUG信息：

```javascript
if(chapters.length === 0) {
  // 返回调试信息，显示页面上的前10个链接
  return JSON.stringify([{
    id: 'DEBUG', 
    title: `Total:${allLinks.length} Samples:${chapterLinks.join('|')}`
  }]);
}
```

从DEBUG输出可以看到，页面上有17个链接，但都是导航链接（`/comics`, `/topic`, `/filter`等），没有章节链接。

### 修复方案

更新章节选择器以匹配当前网站结构：

```javascript
const selectors = [
  'ul.links-of-books li a',        // 新增：拷贝漫画的章节列表容器
  '.links-of-books a',              // 新增：备用选择器
  'div[class*="chapter"] a',        // 新增：包含chapter类名的容器
  'a[href*="/comic/"][href*="/chapter/"]'  // 更精确的链接匹配
];
```

同时添加通用回退方法：

```javascript
if(chapters.length === 0) {
  // 通用方法：查找所有包含/comic/和/chapter/的链接
  const allLinks = document.querySelectorAll('a[href]');
  allLinks.forEach(link => {
    const href = link.getAttribute('href');
    const title = link.textContent.trim();
    if(href && href.includes('/comic/') && href.includes('/chapter/') 
       && title && title.length > 0 && title.length < 100
       && title !== '開始閱讀' && title !== '开始阅读' && title !== '继续阅读') {
      chapters.push({id: href, title: title});
    }
  });
}
```

## 问题3：页面列表URL拼接错误

### 问题表现

从阅读器日志（line 127, 171）可以看到：
```
导航到: https://www.2025copy.comDEBUG
```

URL拼接错误！应该是：
```
https://www.2025copy.com/comic/yuxiangcunbmjdlaxj/chapter/xxx
```

### 原因分析

查看`getPageList`的URL配置（line 584）：

```json
{
  "type": "navigate",
  "url": "{{baseUrl}}{{chapterId}}"
}
```

问题在于：
- `baseUrl` = `"https://www.2025copy.com"`
- `chapterId` = `"DEBUG"`（因为章节提取失败）
- 拼接结果 = `"https://www.2025copy.comDEBUG"` ❌

**正确的逻辑**：
- `chapterId`应该是完整路径，如：`"/comic/yuxiangcunbmjdlaxj/chapter/xxx"`
- 拼接应该是：`baseUrl + chapterId`

### 修复方案

修改URL模板：

```json
{
  "type": "navigate",
  "url": "https://www.2025copy.com{{chapterId}}",
  "description": "导航到章节阅读页（chapterId是完整路径如/comic/xxx/chapter/yyy）"
}
```

这样：
- `chapterId` = `"/comic/yuxiangcunbmjdlaxj/chapter/xxx"`
- 拼接结果 = `"https://www.2025copy.com/comic/yuxiangcunbmjdlaxj/chapter/xxx"` ✅
