# 登录和用户头像功能实现总结

## ✅ 已完成的功能

### 1. 修复登录对话框显示问题

#### 问题描述
- 点击登录按钮后，登录对话框无法正常显示
- 点击对话框内容区域会导致对话框关闭

#### 解决方案
在登录对话框的内容区域添加空的onClick事件处理，阻止事件冒泡：

```typescript
Column() {
  // 登录对话框内容
}
.onClick(() => {
  // 阻止事件冒泡，防止关闭对话框（通过空函数实现）
})
```

外层背景区域保留关闭逻辑：
```typescript
Column() {
  // 对话框容器
}
.onClick(() => {
  // 点击背景关闭对话框
  this.showLoginDialog = false;
})
```

#### 2.3 登录完成后获取用户头像
```typescript
private async completeLogin(): Promise<void> {
  try {
    // 从WebView获取cookie
    await this.authManager.captureCookiesFromController(...);
    
    // 更新登录状态
    this.isLoggedIn = true;
    
    // 获取用户头像
    await this.loadUserAvatar();
    
    // 重新加载标签配置
    await this.loadTabsConfig();
    
    // 关闭对话框
    this.showLoginDialog = false;
    
    promptAction.showToast({ message: '登录成功' });
  } catch (error) {
    logger.error(TAG, '完成登录失败', String(error));
  }
}
```

#### 2.4 加载用户头像方法
```typescript
private async loadUserAvatar(): Promise<void> {
  try {
    if (!this.mangaSourceEngine) {
      logger.warn(TAG, 'WebView引擎未初始化，无法获取用户头像');
      return;
    }
    
    // 调用getUserAvatar方法获取用户头像
    const result = await this.mangaSourceEngine.getUserAvatar();
    
    if (result.success && result.data) {
      this.userAvatarUrl = result.data;
      logger.info(TAG, `获取用户头像成功: ${this.userAvatarUrl}`);
    } else {
      logger.warn(TAG, '获取用户头像失败或未配置');
    }
  } catch (error) {
    logger.error(TAG, '加载用户头像失败', String(error));
  }
}
```

### 3. WebView引擎支持

#### 3.1 添加工作流类型
在`MangaSourceTypes.ets`中添加：

```typescript
export enum WorkflowType {
  // ... 其他类型
  GET_USER_AVATAR = 'getUserAvatar'
}

export interface Workflow {
  // ... 其他工作流
  [WorkflowType.GET_USER_AVATAR]?: Action[];
}
```

#### 3.2 实现getUserAvatar方法
在`MangaSourceEngine.ets`中添加：

```typescript
async getUserAvatar(): Promise<EngineResult<string>> {
  const startTime = Date.now();
  
  try {
    if (!this.config) {
      return {
        success: false,
        error: '配置未加载',
        duration: Date.now() - startTime,
        actionCount: 0
      };
    }
    
    // 获取getUserAvatar工作流
    const actions = this.configParser.getWorkflow(this.config, 'getUserAvatar');
    
    if (!actions || actions.length === 0) {
      return {
        success: false,
        error: '未配置getUserAvatar工作流',
        duration: Date.now() - startTime,
        actionCount: 0
      };
    }
    
    // 创建执行上下文
    const context = this.createActionContext();
    await this.populateSourceSettings(context);
    context.variables['useCookies'] = 'true';  // 获取头像需要登录
    
    // 执行工作流
    let avatarUrl = '';
    for (let i = 0; i < actions.length; i++) {
      const action = actions[i];
      const result = await this.actionEngine.executeAction(action, context);
      
      if (!result.success) {
        throw new Error(`获取用户头像失败: ${result.error}`);
      }
      
      // 从结果中提取头像URL
      if (result.data) {
        if (typeof result.data === 'string') {
          avatarUrl = result.data;
        } else if (typeof result.data === 'object') {
          const dataObj = result.data as Record<string, Object>;
          avatarUrl = String(dataObj['avatarUrl'] || dataObj['avatar'] || dataObj['url'] || '');
        }
      }
    }
    
    if (!avatarUrl) {
      return {
        success: false,
        error: '未能提取头像URL',
        duration: Date.now() - startTime,
        actionCount: actions.length
      };
    }
    
    return {
      success: true,
      data: avatarUrl,
      duration: Date.now() - startTime,
      actionCount: actions.length
    };
    
  } catch (error) {
    return {
      success: false,
      error: error instanceof Error ? error.message : String(error),
      duration: Date.now() - startTime,
      actionCount: 0
    };
  }
}
```

## 📝 图源JSON配置示例

图源需要在JSON配置中添加`getUserAvatar`工作流：

```json
{
  "workflows": {
    "getUserAvatar": [
      {
        "type": "navigate",
        "url": "https://example.com/user/profile"
      },
      {
        "type": "extract",
        "selector": ".user-avatar img",
        "attribute": "src",
        "variable": "avatarUrl"
      }
    ]
  }
}
```

### 工作流说明

1. **navigate**: 导航到用户个人资料页面
2. **extract**: 提取头像图片的URL
   - `selector`: CSS选择器，定位头像元素
   - `attribute`: 提取的属性（通常是`src`）
   - `variable`: 保存到变量`avatarUrl`

### 支持的返回格式

getUserAvatar工作流可以返回以下格式：

1. **字符串**: 直接返回头像URL
   ```json
   "https://example.com/avatar.jpg"
   ```

2. **对象**: 包含头像URL的对象
   ```json
   {
     "avatarUrl": "https://example.com/avatar.jpg"
   }
   ```
   或
   ```json
   {
     "avatar": "https://example.com/avatar.jpg"
   }
   ```
   或
   ```json
   {
     "url": "https://example.com/avatar.jpg"
   }
   ```

## 🎯 功能流程

### 登录流程
```
用户点击登录按钮
    ↓
显示登录对话框
    ↓
用户在WebView中登录
    ↓
点击"完成登录"按钮
    ↓
捕获Cookie
    ↓
获取用户头像 (getUserAvatar)
    ↓
更新登录状态和头像
    ↓
关闭对话框
    ↓
显示用户头像
```

### 头像显示逻辑
```
检查登录状态
    ↓
未登录 → 显示默认图标
    ↓
已登录 → 检查头像URL
    ↓
有头像URL → 显示用户头像
无头像URL → 显示默认图标
```

## 🔧 技术细节

### 1. 事件冒泡处理
- 外层背景：点击关闭对话框
- 内层内容：空onClick阻止冒泡

### 2. 头像URL类型
- 支持网络URL（http/https）
- 支持相对路径（需要图源baseUrl）
- 支持data URI

### 3. 错误处理
- 配置未加载：返回失败
- 工作流未配置：返回失败并记录警告
- 执行失败：返回失败并记录错误
- 未提取到URL：返回失败

### 4. 日志记录
- 开始获取：INFO级别
- 执行步骤：DEBUG级别
- 成功获取：INFO级别
- 失败情况：WARN/ERROR级别
