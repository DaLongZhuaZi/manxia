# 拷贝漫画筛选功能使用说明

## ⚠️ 重要：必须重新导入图源配置

由于添加了新的 `filter` 工作流，**必须重新导入JSON配置文件**，否则会报错：
```
❌ 错误 [MangaSourceEngine] 筛选漫画失败: 缺少筛选工作流配置
```

### 📝 重新导入步骤

1. **删除旧图源**（可选，但推荐）
   - 进入图源管理
   - 找到"拷贝漫画 (WebView)"
   - 删除图源

2. **重新导入JSON**
   - 进入图源管理
   - 点击"导入图源"
   - 选择 `copymanga_webview.json`
   - 确认导入

3. **验证导入成功**
   - 进入图源详情页
   - 应该看到三个标签：热门、最新、**筛选**
   - 点击筛选标签，应该显示三个选择按钮

## 🎯 筛选功能使用

### UI布局

筛选标签页顶部有三个并排的选择按钮：

```
┌─────────────────────────────────────┐
│  [时间↓]  [全部地区]  [全部题材]   │
└─────────────────────────────────────┘
```

### 选择器说明

#### 1️⃣ 排序选择器
点击第一个按钮，选择排序方式：
- 按时间-从新到旧 ⭐（默认）
- 按时间-从旧到新
- 按热度-从高到低
- 按热度-从低到高

#### 2️⃣ 地区选择器
点击第二个按钮，选择地区：
- 全部 ⭐（默认）
- 日漫
- 韩漫
- 美漫

#### 3️⃣ 题材选择器
点击第三个按钮，选择题材（共34个选项）：
- 全部 ⭐（默认）
- 愛情、歡樂向、冒險、奇幻、百合
- 校园、科幻、東方、耽美、生活
- 格鬥、轻小说、悬疑、萌系、神鬼
- 职场、治愈、搞笑、竞技、魔幻
- 热血、美食、励志、侦探、惊悚
- 异世界、战争、历史、都市、穿越
- 重生、恐怖、武侠
- ...等

### 使用流程

1. **进入筛选页面**
   - 打开拷贝漫画图源详情页
   - 点击"筛选"标签

2. **设置筛选条件**
   - 点击任意选择按钮
   - 在弹出的选择器中选择选项
   - 点击"确定"

3. **自动刷新结果**
   - 选择后会自动保存设置
   - 自动刷新筛选结果
   - 显示符合条件的漫画

4. **修改筛选条件**
   - 可以随时点击按钮修改条件
   - 每次修改都会自动刷新结果

## 🔧 技术细节

### URL拼接规则

筛选通过URL参数实现：
```
基础URL: https://www.2025copy.com/comics?

参数拼接:
- ordering={排序值}  （必选）
- region={地区值}    （可选，不选=全部）
- theme={题材值}     （可选，不选=全部）

示例URL:
https://www.2025copy.com/comics?theme=aiqing&region=0&ordering=-datetime_updated
```

### 设置保存

筛选条件会保存到数据库：
- 键名：`filterOrdering`、`filterRegion`、`filterTheme`
- 作用域：每个图源独立保存
- 持久化：下次打开自动恢复上次的筛选条件

### 性能优化

筛选页面也应用了性能优化：
- 初始等待：1.5秒
- 滚动后等待：500ms × 2
- 总加载时间：约2.5秒
- 使用`data-src`属性，无需等待图片加载

## 🐛 常见问题

### Q1: 点击筛选标签显示"缺少筛选工作流配置"
**A:** 需要重新导入JSON配置文件（见上方步骤）

### Q2: 筛选结果为空
**A:** 可能的原因：
- 筛选条件过于严格，没有符合的漫画
- 网络问题，尝试刷新
- 检查日志是否有错误

### Q3: 选择器不显示
**A:** 确保：
- 已切换到"筛选"标签页
- 图源配置已正确导入
- WebView系统正常工作

### Q4: 修改筛选条件后没有刷新
**A:** 
- 检查是否点击了"确定"而非"取消"
- 查看日志确认设置是否保存成功
- 尝试手动切换到其他标签再切回来

## 📊 与其他标签的区别

| 标签 | 数据来源 | 可配置 | 说明 |
|------|---------|--------|------|
| **热门** | 固定URL | ❌ | 显示推荐的热门漫画 |
| **最新** | 固定URL | ❌ | 显示最新更新的漫画 |
| **筛选** | 动态URL | ✅ | 根据用户选择的条件筛选 |
