# 在线漫画阅读修复方案

## 问题分析

### 从日志中发现的关键问题

1. **图片加载失败但仍显示旧图片**
   - 日志7013行：`Failed to create image loader`
   - 日志7023行：`开始显示图片: pixelMap=false`
   - **原因**：Image组件在加载失败后没有清除旧的显示内容

2. **没有"加载中"状态**
   - 连续翻页直接显示"加载失败"
   - **原因**：状态管理不完善，UI更新不及时

3. **预加载队列不透明**
   - 无法看到预加载的实际情况
   - 难以调试预加载逻辑问题

## 解决方案

### 一、修复图片加载状态同步问题

#### 1.1 在 MangaViewer.ets 中增强状态管理

**问题位置**：
- `imageLoadStates` Map 需要更严格的状态控制
- Image组件的 `onError` 回调需要立即清除显示

**修复要点**：
```typescript
// 在图片加载失败时，立即更新UI状态
onError: (error) => {
  // 1. 更新状态为失败
  this.imageLoadStates.set(pageId, ImageLoadState.ERROR);
  
  // 2. 清除PixelMap（关键！）
  this.pagePixelMaps.delete(pageId);
  
  // 3. 重置Image输入为占位符
  if (this.singlePagePageId === pageId) {
    this.singlePageImageInput = $r('app.media.ic_error');
  }
  
  // 4. 触发UI刷新
  this.forceRenderUpdate();
}
```

#### 1.2 添加加载中状态的明确显示

**在 buildSinglePageContent 中**：

### 二、优化预加载流程

#### 2.1 预加载队列管理

**创建专门的预加载管理器**：
```typescript
class PreloadManager {
  private queue: PreloadItemInfo[] = [];
  private loading: Set<number> = new Set();
  private completed: Set<number> = new Set();
  private failed: Set<number> = new Set();
  
  // 添加到队列
  addToQueue(pageIndex: number, priority: number) {
    // 去重、排序、限制队列长度
  }
  
  // 开始加载
  async startLoad(pageIndex: number) {
    this.loading.add(pageIndex);
    // 更新调试信息
    this.updateDebugInfo();
  }
  
  // 完成加载
  onLoadComplete(pageIndex: number, success: boolean) {
    this.loading.delete(pageIndex);
    if (success) {
      this.completed.add(pageIndex);
    } else {
      this.failed.add(pageIndex);
    }
    this.updateDebugInfo();
  }
  
  // 获取调试信息
  getDebugInfo(): PreloadDebugInfo {
    return {
      currentPage: this.currentPage,
      totalPages: this.totalPages,
      preloadRange: this.preloadRange,
      queueItems: this.queue,
      completedCount: this.completed.size,
      failedCount: this.failed.size,
      memCacheHits: this.stats.memCacheHits,
      diskCacheHits: this.stats.diskCacheHits,
      networkLoads: this.stats.networkLoads
    };
  }
}
```

#### 2.2 在 MangaViewer 中集成预加载管理器

```typescript
@Component
export struct MangaViewer {
  // 预加载管理器
  private preloadManager: PreloadManager = new PreloadManager();
  
  // 预加载调试信息
  @State private preloadDebugInfo: PreloadDebugInfo = {
    currentPage: 0,
    totalPages: 0,
    preloadRange: 2,
    queueItems: [],
    completedCount: 0,
    failedCount: 0,
    memCacheHits: 0,
    diskCacheHits: 0,
    networkLoads: 0
  };
  
  // 在图片加载时更新统计
  private async loadImageWithTracking(pageIndex: number, url: string) {
    const startTime = Date.now();
    
    // 标记为加载中
    this.preloadManager.startLoad(pageIndex);
    
    try {
      // 尝试内存缓存
      const memCached = this.getFromMemCache(url);
      if (memCached) {
        this.preloadDebugInfo.memCacheHits++;
        this.preloadManager.onLoadComplete(pageIndex, true);
        return memCached;
      }
      
      // 尝试磁盘缓存
      const diskCached = await this.getFromDiskCache(url);
      if (diskCached) {
        this.preloadDebugInfo.diskCacheHits++;
        this.preloadManager.onLoadComplete(pageIndex, true);
        return diskCached;
      }
      
      // 网络加载
      this.preloadDebugInfo.networkLoads++;
      const result = await this.loadFromNetwork(url);
      this.preloadManager.onLoadComplete(pageIndex, true);
      return result;
      
    } catch (error) {
      this.preloadManager.onLoadComplete(pageIndex, false);
      throw error;
    }
  }
}
```

### 三、集成 PreloadDebugOverlay

#### 3.1 在 MangaReaderPage 中添加

```typescript
@Entry
@Component
struct MangaReaderPage {
  // 预加载调试模式：'off' | 'on' | 'always'
  @StorageLink('preload_debug_mode') preloadDebugMode: string = 'off';
  
  // 控制栏可见性
  @State private controlsVisible: boolean = false;
  
  // 预加载调试信息
  @State private preloadDebugInfo: PreloadDebugInfo = { /* ... */ };
  
  build() {
    Stack() {
      // 漫画查看器
      MangaViewer({
        // ... 其他参数
        preloadDebugInfo: $preloadDebugInfo
      })
      
      // 顶部控制栏
      if (this.controlsVisible) {
        this.buildTopBar()
      }
      
      // 底部控制栏
      if (this.controlsVisible) {
        this.buildBottomBar()
      }
      
      // 预加载调试 Overlay
      Column() {
        Blank()
        
        // 显示条件：
        // 1. always 模式：始终显示
        // 2. on 模式：控制栏可见时显示
        if (this.preloadDebugMode === 'always' || 
            (this.preloadDebugMode === 'on' && this.controlsVisible)) {
          PreloadDebugOverlay({
            debugInfo: $preloadDebugInfo,
            visible: true
          })
            .margin({ bottom: 60 }) // 在页码信息下方
        }
      }
      .width('100%')
      .height('100%')
      .padding({ left: 16, right: 16, bottom: 16 })
    }
    .onClick(() => {
      // 点击屏幕切换控制栏可见性
      this.controlsVisible = !this.controlsVisible;
    })
  }
}
```

## 测试验证

### 测试场景

1. **快速翻页测试**
   - 连续快速翻页10页
   - 验证：不应出现"加载失败"和旧图片同时显示

2. **网络波动测试**
   - 在弱网环境下翻页
   - 验证：应显示"加载中"状态，失败后显示"加载失败"

3. **预加载调试测试**
   - 开启预加载调试模式
   - 验证：能看到实时的预加载队列信息

4. **模式切换测试**
   - 测试 off/on/always 三种模式
   - 验证：模式切换正常，显示/隐藏符合预期

## 注意事项

1. **性能考虑**
   - 预加载调试信息的更新频率不宜过高
   - 建议使用节流（throttle）限制更新频率为 100ms

2. **内存管理**
   - 预加载队列应有最大长度限制（建议20项）
   - 及时清理已完成的预加载项

3. **用户体验**
   - "常驻"模式下，Overlay 应半透明，不遮挡阅读
   - 提供快速关闭预加载调试的方式

## 预期效果

- ✅ 不会出现"加载失败"和旧图片同时显示
- ✅ 翻页时能看到明确的"加载中"状态
- ✅ 加载失败时显示错误提示和重试按钮
- ✅ 预加载队列透明可见（调试模式下）
- ✅ 逻辑流程清晰，易于调试和维护
