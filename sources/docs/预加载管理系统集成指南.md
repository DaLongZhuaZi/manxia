# 预加载管理系统集成指南

## 新架构概述

### 核心组件

1. **PreloadManager** - 预加载队列管理
   - 管理预加载队列和优先级
   - 统计缓存命中率
   - 提供调试信息

2. **ImageLoadStateManager** - 图片加载状态管理
   - 统一管理所有页面的加载状态
   - 管理 PixelMap 生命周期
   - 确保状态与UI同步

3. **PreloadDebugOverlay** - 调试信息显示
   - 实时显示预加载队列
   - 显示缓存统计
   - 可配置显示模式

**新的统一预加载方法：**

```typescript
/**
 * 统一的预加载方法
 */
private triggerPreload(): void {
  if (!this.chapter || !this.chapter.pages) {
    return;
  }

  const currentIndex = this.currentPageIndex;
  const totalPages = this.chapter.pages.length;
  const range = this.getDynamicPreloadRange();

  // 更新预加载管理器的页面信息
  this.preloadManager.setPageInfo(currentIndex, totalPages);
  this.preloadManager.setPreloadRange(range);

  // 计算预加载范围
  const startIndex = Math.max(0, currentIndex - range);
  const endIndex = Math.min(totalPages - 1, currentIndex + range);

  // 批量添加预加载任务
  const tasks: Array<{ pageIndex: number; pageId: string; url: string; priority: number }> = [];

  for (let i = startIndex; i <= endIndex; i++) {
    const page = this.chapter.pages[i];
    if (!page) continue;

    // 计算优先级：距离当前页越近，优先级越高
    const distance = Math.abs(i - currentIndex);
    const priority = range - distance + 1;

    tasks.push({
      pageIndex: i,
      pageId: page.id,
      url: page.imageUrl || '',
      priority
    });
  }

  this.preloadManager.addBatch(tasks);

  // 开始加载队列中的图片
  this.processPreloadQueue();
}

/**
 * 处理预加载队列
 */
private processPreloadQueue(): void {
  // 获取下一个要加载的项
  const next = this.preloadManager.getNextToLoad();
  if (!next) {
    return;
  }

  // 检查是否已经在加载或完成
  if (this.imageLoadStateManager.isLoading(next.pageId) ||
      this.imageLoadStateManager.isCompleted(next.pageId)) {
    return;
  }

  // 开始加载
  this.loadPageImage(next.pageIndex, next.pageId, next.url);
}
```

### 4. 修改图片加载方法

```typescript
/**
 * 加载页面图片（统一入口）
 */
private async loadPageImage(pageIndex: number, pageId: string, url: string): Promise<void> {
  // 标记为加载中
  this.preloadManager.startLoad(pageIndex);
  this.imageLoadStateManager.startLoading(pageId);

  try {
    // 1. 检查内存缓存
    const memCached = this.imageLoadStateManager.getPixelMap(pageId);
    if (memCached) {
      this.preloadManager.markMemCacheHit(pageIndex);
      this.preloadManager.onLoadComplete(pageIndex, true, 'mem');
      return;
    }

    // 2. 检查磁盘缓存
    const diskCached = await this.loadFromDiskCache(url);
    if (diskCached) {
      this.imageLoadStateManager.onLoadComplete(pageId, diskCached);
      this.preloadManager.markDiskCacheHit(pageIndex);
      this.preloadManager.onLoadComplete(pageIndex, true, 'disk');
      return;
    }

    // 3. 网络加载
    this.preloadManager.markNetworkLoad(pageIndex);
    const pixelMap = await this.loadFromNetwork(url);
    
    this.imageLoadStateManager.onLoadComplete(pageId, pixelMap);
    this.preloadManager.onLoadComplete(pageIndex, true, 'network');

  } catch (error) {
    const errorMsg = String(error);
    this.imageLoadStateManager.onLoadError(pageId, errorMsg);
    this.preloadManager.onLoadComplete(pageIndex, false, undefined, errorMsg);
  }
}
```

```typescript
/**
 * 构建单页内容（带状态显示）

@Builder
buildSinglePageContent() {
  Stack() {
    // 底层：图片
    Image(this.getSinglePageImageInput(this.currentPageIndex))
      .objectFit(ImageFit.Contain)
      .width('100%')
      .height('100%')

    // 中层：加载中指示器
    if (this.getPageLoadState(this.currentPageIndex) === ImageLoadState.LOADING) {
      Column() {
        LoadingProgress()
          .width(50)
          .height(50)
          .color(Color.White)
        Text('加载中...')
          .fontSize(14)
          .fontColor(Color.White)
          .margin({ top: 8 })
      }
      .width('100%')
      .height('100%')
      .justifyContent(FlexAlign.Center)
      .backgroundColor('#80000000')
    }

    // 顶层：错误提示
    if (this.getPageLoadState(this.currentPageIndex) === ImageLoadState.ERROR) {
      Column() {
        Image($r('app.media.ic_error'))
          .width(60)
          .height(60)
        Text('加载失败')
          .fontSize(14)
          .fontColor(Color.White)
          .margin({ top: 8 })
        Button('重试')
          .fontSize(14)
          .margin({ top: 12 })
          .onClick(() => {
            this.retryLoadPage(this.currentPageIndex);
          })
      }
      .width('100%')
      .height('100%')
      .justifyContent(FlexAlign.Center)
      .backgroundColor('#80000000')
    }
  }
  .width('100%')
  .height('100%')
}

/**
 * 获取页面加载状态
 */
private getPageLoadState(pageIndex: number): ImageLoadState {
  const page = this.chapter?.pages[pageIndex];
  if (!page) {
    return ImageLoadState.IDLE;
  }
  return this.imageLoadStateManager.getLoadState(page.id);
}

/**
 * 重试加载页面
 */
private retryLoadPage(pageIndex: number): void {
  const page = this.chapter?.pages[pageIndex];
  if (!page) {
    return;
  }
  
  this.imageLoadStateManager.clearPage(page.id);
  this.preloadManager.clearPage(pageIndex);
  
  this.loadPageImage(pageIndex, page.id, page.imageUrl || '');
}
```

### 7. 页面切换时的处理

```typescript
/**
 * 页面索引变化时
 */
private onPageIndexChange(newIndex: number): void {
  this.currentPageIndex = newIndex;
  
  // 更新预加载管理器的当前页
  this.preloadManager.setPageInfo(newIndex, this.chapter.pages.length);
  
  // 触发新的预加载
  this.triggerPreload();
  
  // 清理远离当前页的资源
  this.imageLoadStateManager.cleanupDistantPages(newIndex, 5);
  this.preloadManager.cleanupDistantCompleted(10);
}
```

## 注意事项

1. **PixelMap 生命周期管理**
   - 所有 PixelMap 的创建和释放都由 ImageLoadStateManager 管理
   - 确保不再使用时及时释放，避免内存泄漏

2. **状态同步**
   - 图片加载状态的变化必须通过 ImageLoadStateManager
   - UI 显示必须基于 ImageLoadStateManager 的状态

3. **性能优化**
   - 调试信息更新使用节流，避免频繁更新
   - 及时清理远离当前页的资源

4. **错误处理**
   - 所有加载错误都要通过 onLoadError 记录
   - 提供重试机制

5. **向后兼容**
   - 保留必要的旧接口，逐步迁移
   - 确保不影响现有功能
